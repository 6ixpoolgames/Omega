# Historical Probe Results

This folder archives compact result artifacts from earlier Omega validation
branches.

These outputs are retained for provenance, controls, and failure analysis. They
are not the current validation center. Current work should use:

```text
results/val0_g/<run-id>/
results/val0_ct/<run-id>/
```

for VAL0-G and VAL0-CT runs, and `results/local_runs/` for ignored smoke or
calibration outputs.
