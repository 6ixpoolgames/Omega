# Enabling strength, matched preparations and predictive retention

New experiment, frozen 2026-10-13 before ranking. The prior results remain intact.
The underlying local reaction model, energies, reservoirs and bills are unchanged.
The four active capture multipliers are 1,3,6,12. Multiplier1 removes the active
capture benefit while retaining service chemistry, wear, gates and physical state.
Changing that multiplier is a law contrast; each preparation/control comparison
inside a multiplier uses the same law and incident reservoir.

## Control extension and paid idle

Each inactive/active observation selects one of six response weight pairs
(service,export): (0,0),(1,0),(.75,.25),(.5,.5),(.25,.75),(0,1).
Four independent table entries give 6^4=1296 policies. The 3^4=81 policies using
only idle/service/export are called deterministic-or-idle settings; native physics
is still stochastic. The primary optimizer sees full-world sampled breadth.

Idle closes the actuator pathways and retains the current gate. It pays time,
wear exposure and forgone opportunities, not an invented positive fuel toll.
Changing gates retains the existing fuel-paid reversible implementation. Idle
does not hold apparatus or fuel fixed and does not pause the world. Sensing/table
hardware remains the declared idealized catalytic coupling from the base model.

Some idle policies fix one or both gate states. The solver enumerates the actual
reachable class from the gates-service energy-matched preparations, rather than
applying an irreducible stationary solve to all 144 states. At least 36 and at most
144 states occur. No inaccessible initial gate class receives an arbitrary weight.
Both active and precursor roots, and every reference-shell state, belong to that
same reachable class. Distinct closed gate classes are separate physical queries.

## Matched randomized reference

The reference contains every resolved state with energy4 and both gates service,
uniformly weighted. This includes the organized root: the reference does not
exclude favorable arrangements by definition. Same material, energy, hardware,
drive, clock and policy apply. For each state x compute conditional history bits
ell_T(x), then average those bits. H(reference) is not added. This is an explicitly
declared preparation ensemble, not evidence that a thermal molecular gas was built.
The first testbed resolves no translational molecular motion.

Report finite profiles and asymptotic root-minus-shell offsets. Within one finite
irreducible reachable class all roots share the rate. A preparation advantage
can therefore be a bounded offset; a policy/law change can alter the rate.

## RuleA-R1: optional retained predictive distinctions

We do not adopt a persistence admission gate. We assess one operational version
of Rule A, defined here before new results:

    R_x(delta,tau) = I(X_delta; X_(delta+tau) | X_0=x)
                  = H(P_(delta+tau)(x,.))
                    - sum_y P_delta(x,y) H(P_tau(y,.)).

It asks how much of the uncertainty introduced by the next sampled development
remains inferable from the later full physical state. A distinction may move to
a different variable and still count. A variable need not literally stay fixed.
Full-state gate memory counts equally with apparatus and resource distinctions.
No organism, maintenance, usefulness or coherence bonus enters this profile.

At tau0 this equals one-step entropy. It is nonnegative and, for the specified
Markov law, nonincreasing with tau by data processing. In these finite mixing
classes it approaches0. Bits at different lags overlap: never add them up and
call the result a continuation volume. Nor does a larger R prove greater capacity
or better ethics. Long-lived gate correlations may dominate it.

Common physical lags0,.25,1,4,16,64 apply to every policy and multiplier. The
overlay reports organized/disassembled roots, matched-shell average and stationary
average. No threshold is selected after inspecting results. No claim that these
lags isolate every thermal fluctuation or constitute a universal physical grain.

The report compares selected diagnostic policies under this overlay, flags
rank disagreement with unfiltered breadth, and leaves the primary verdict intact.
Only the breadth grid is fully optimized; the overlay's best listed candidate
is not a certified Rule A optimum. Sensitivity cadences similarly compare listed
candidates rather than reoptimizing all1296 policies.

## Automated interpretation

Each report includes exact grid scope, root/reference matching, every effect
sign, finite and rate/offset outcomes, functioning/work/heat/switching/recovery
surveys, gate-versus-body/fuel entropy allocation, and Rule A disagreement.
Increasing capture strength does not guarantee a protection or breadth advantage.
The response is discovered, not built into the criterion.

The experiment locates boundaries only on its four registered multipliers and
its quarter-step control grid. Any finer search is subsequent exploration.
Paid population growth and new capacity sites remain the next expansion, not
phenomena inferred from a higher capture multiplier.
