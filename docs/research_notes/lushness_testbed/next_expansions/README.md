## The question

Does native weighted continuation make an optimizer preserve, restore or expand
the physical conditions of continuation, including those of another organization?
Give the world mechanisms through which protection and appropriation can matter,
then inspect the optimizer's behavior. Do not reward the desired interpretation.

The last shock batch validates physical mechanisms but does not demonstrate adaptive
protection: all embodied winners choose active servicing. Conditional reserve rises
slightly with correlation while function availability and unconditional post-probe
function fall. These findings remain unchanged and must be included in the next report.

## Commitments shared by every stage

- Primary breadth remains native sampled physical-state history entropy/perplexity.
  Randomness counts. Rule A stays parked. No survival, equality or generativity bonus.
- Harm/generativity/recovery are interpretations of lawful effects on continuation
  and access. Functioning stock, resource concentration and pump use are diagnostics.
- Compare preparations under a common law, resources, drive, cadence and declared
  frame. Changes to a module or controller information are mechanism contrasts.
- Preserve all post-collapse dynamics. Policy-free basal gate relaxation remains;
  no resetting gates or deleting tails to manufacture a preferred winner.
- Temporary absence, costly reversible loss, policy-induced inaccessibility and
  structural impossibility are distinct. An arbitrarily slow positive route counts
  in support reachability, with its small probability exposed by deadline readouts.
- Coarse apparatus populations are not established valuers. Do not infer personhood,
  criticality, open-ended generativity or ethical adequacy from an optimizer ranking.

## Architecture and workflow

Reuse Event/RuleModule/WorldSpec, compiler, finite_classes, channel_access,
event_sequences, shock_resilience, registry, and immutable snapshot execution.
Extend ControllerSpec with explicit observation and physical-action contracts.
Add named QuerySpec records when access/intervention queries no longer fit existing
dictionaries. No semantic category enters the physical state merely for scoring.

Each module declares state fields, dependencies, native events, support, energy and
resource ledgers, disabled-mode mapping, and readout applicability. Pairwise thermal
channels must retain their forward/reverse ratios. Nonthermal boundaries declare
work/heat conventions. A zero rate is either a physical constraint or an explicit
idealization, not a numerical cutoff. Logical module names do not create entropy.

The same event enumerator serves exact and sampled modes. Cache equivalence must
include physical kernels AND requested ledgers/readouts. Policy aliases are labels,
not additional possibilities. Cache new physical/readout versions separately.

Before scientific ranking, file machine-readable cases, predictions, comparison
subject, horizon/rate-offset convention, tie tolerance, resource cap, estimator and
stopping rule. Freeze the list of cases as well as code. Parameter feasibility may
use fixed-controller calibration without policy rankings; disclose it. A hypothesis
failure does not authorize a new range under the original preregistration.

Default engineering caps:120s/1GiB/256MiB for tiny smoke;600s/1GiB/256MiB for one
complete larger evaluation; one numerical thread. Maximum two concurrent jobs only
when measured combined memory permits. Every larger search has a separate budget.
Report incomplete/capped jobs and retain their status. No quiet inventory reduction.

Keep compact all-candidate results and adverse findings. Reference shared policy
and world records by ID to avoid repeated JSON payloads; serialize published JSON
compactly. Keep large vectors/traces local and reconstructible. Retain hashes,
seeds, environment, numerical residuals and actual runtime/memory. Pin filed
evidence; current eviction remains dry-run. No automatic deletion, push or upload.

## Completion gates

1. Backward compatibility and analytic physical fixtures pass.
2. State count, full-query time and peak memory are measured.
3. The controller can physically express at least two distinct allocations with
   different downstream consequences. This is a capability check, not a test that
   protection must win.
4. Frozen predictions distinguish policy adaptation from a changed stationary
   distribution under an unchanged policy.
5. Reports show unconditional outcomes beside conditional recovery/reserve, every
   baseline, all ties, uncertainty and every failed prediction.

Public deliverables per stage: implementation notes, focused tests, engineering
report, updated limitations registry, and a draft scientific protocol. Only a later
explicit launch instruction freezes and executes a new scientific batch.
