## Generated Dynamics

The strict environments share:

```text
world-state interface;
action interface;
constant observation map;
initial state;
and two-step horizon.
```

The actions contribute base trajectory facts:

```text
x -> A
y -> B
z -> C
```

Order-dependent third-fact realization differs:

```text
north:
  x,y -> A,B,C

south:
  y,x -> A,B,C
```

Candidate incidence is derived only from the accumulated facts encoded by the
terminal world state. Controller identifiers, environment identifiers, and
witness identifiers do not enter the candidate predicates.

The constant observation stream means a controller generates the same action
sequence in both strict environments. The environments nevertheless transform
that common sequence differently.

## Strict Separation

Both environments individually admit the triple:

| Scope | Triple-securing behavior |
|---|---|
| `north` | `xy` |
| `south` | `yx` |
| `north, south` | none |

The complete strict May object contains four concrete triple witnesses across
the 72 generated controller/environment runs.

Every pair is Robust over the same full environment scope:

| Family | Full-scope securing behaviors | Securing controllers |
|---|---|---:|
| `A,B` | `xy`, `yx` | 4 |
| `A,C` | `xz`, `zx` | 4 |
| `B,C` | `yz`, `zy` | 4 |

Therefore:

```text
May({A,B,C}):
  true

Robust_north({A,B,C}):
  true

Robust_south({A,B,C}):
  true

Robust_{north,south}({A,B,C}):
  false
```

This is the quantifier separation:

```text
for every environment, there exists a triple-realizing controller

does not imply

there exists one controller that realizes the triple in every environment.
```

The result is stronger than placing one impossible environment in the scope.
Each strict environment permits the full family; their required controller
behaviors are incompatible under the shared observation stream.

## Next Debt

The next technical question is whether this separation survives when one
controller/environment pair can have several admissible outcomes.

The next protocol should therefore replace:

```text
one deterministic generated run per controller/environment
```

with either:

```text
finite nondeterministic outcome sets;
or exact finite ambiguity-set kernels.
```

The quantifier order must be fixed before the run. No moral interpretation or
new candidate coordinate should be added in that sprint.

## Public Compression

Two environments can each permit three trajectory facts together while
requiring incompatible action orders to obtain them. Across an exhaustively
enumerated bounded controller class, every pair can be secured by one
controller without any one controller securing the triple across both
environments. Joint realizability therefore does not imply joint robust
securability.
