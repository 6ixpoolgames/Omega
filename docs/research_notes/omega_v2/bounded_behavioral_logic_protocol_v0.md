# Bounded Behavioral Logic Protocol v0

Status: preregistration / post-freeze quarantined finite pilot

Scope: finite action-labelled transition systems, bounded alternating
refinement, data-derived semantic comparison universes, and finite
characteristic forcing formulas

Provenance: hardening successor to
`dynamic_continuation_profiles_report_v0.md`; the frozen Omega checkpoint
`cc4c89c` and every retained verdict before it remain unchanged

Claim boundary: not a completeness theorem for ATL, the modal mu-calculus, or
arbitrary transition systems; not value, valuerhood, agency, standing,
identity, moral licensing, universal lushness, or Omega validation

## Purpose

The dynamic continuation pilot used an explicit finite comparison basis `U`.
This pass tests whether the finite basis used by the pilot can instead be
derived from its audited systems and whether the resulting bounded refinement
order admits explicit positive forcing certificates.

The intended reduction is:

```text
declared positive atom grammar
+ exact finite control dynamics
+ bounded horizon
-> finite semantic behavior types
-> data-derived comparison universe
-> characteristic forcing certificates
```

This does not eliminate the positive atom grammar or horizon. It removes the
extra choice of state representatives used only to populate `U`.

## Data-Derived Semantic Universe

For a finite audited family `F` and horizon `h`, define:

```text
Types_h(F) = { B_h(x) | x is a state of a system in F }
```

where `B_h` is the retained duplicate-resistant behavior signature.

The derived profile is:

```text
DerivedCap_h(x ; F) =
  { fingerprint(t) | t in Types_h(F) and t <=_h B_h(x) }
```

The preorder `<=_h` is computed structurally on behavior signatures using the
same action-before-outcome quantifiers as the state-level alternating
refinement relation.

The audited family remains explicit evidence scope. It is not a universal
capability domain.

## Bounded Forcing Grammar

Use the finite positive grammar:

```text
phi ::= top
      | atom(p)
      | and(phi_1, ..., phi_n)
      | or(phi_1, ..., phi_n)
      | force(phi)
```

with:

```text
x |= force(phi)
  iff there exists one enabled action a at x
      such that every a-successor satisfies phi.
```

The action is chosen before the environment outcome. Action identifiers do not
occur in formulas.

For one behavior signature `t`, construct:

```text
chi_0(t) =
  conjunction of the positive atoms in t

chi_(h+1)(t) =
  conjunction of:
    the positive atoms in t;
    for every action-effect E in t,
      force(disjunction { chi_h(u) | u in E }).
```

The target finite correspondence is:

```text
u <=_h v
iff
v |= chi_h(u)
```

over the audited finite domain.

## Conjunction-Only Audit

Disjunction is not assumed necessary merely because it appears in the
candidate construction.

Compute the semantic extensions generated at depth at most `h` by:

```text
top;
positive atoms;
finite conjunction;
force.
```

Then repeat with finite disjunction enabled.

The audit asks:

```text
Does conjunction-only logic induce the same preorder as <=_h?

If not, does adding disjunction recover the preorder?
```

A bounded witness may establish that disjunction is required for this finite
fragment. It does not establish a general logical minimality theorem.

## Preregistered Cases

### BL1 - Structural/state refinement parity

On retained finite fixtures, structural signature refinement and state-level
alternating refinement must agree at the declared horizon.

### BL2 - Derived-basis parity

Profiles generated from distinct semantic behavior types must agree with
profiles generated by the old representative-state basis over the same audited
systems.

### BL3 - Characteristic certificate correspondence

For every ordered pair of audited behavior types:

```text
u <=_h v
iff
v satisfies chi_h(u).
```

Any mismatch fails the sprint.

### BL4 - Grammar adequacy

Use a finite multi-outcome witness containing:

```text
one action whose outcomes have incomparable positive atoms;
separate refinements retaining either outcome;
an unrelated third outcome.
```

The run records whether conjunction-only formulas recover the signature
preorder and whether adding disjunction does.

### BL5 - Presentation control

State and action relabeling must preserve:

```text
semantic behavior types;
derived profiles;
characteristic certificate truth.
```

## Evidence Classes

Every BL case is an instrument-correctness or finite correspondence check.
This pass has no theory-discovery success criterion.

The predecessor dynamic report will be annotated separately:

```text
instrument correctness:
  duplicate resistance;
  effect-equivalent action resistance;
  novel-branch strictness;
  delayed-divergence depth;
  action/outcome quantifiers;
  deformation classification;
  presentation controls;
  bridge plumbing.

risky retained result:
  adaptive fixed-world behavior strictly refines switching behavior at the
  preregistered finite horizon under sound update.
```

## Success Conditions

The pass succeeds only if:

1. the semantic universe contains no state or action identifiers;
2. BL1 through BL3 hold over the audited domain;
3. the grammar audit reports its result without forcing a preferred answer;
4. formula semantics preserve action-before-outcome quantification;
5. presentation controls pass;
6. no old retained verdict changes.

## Kill Conditions

Stop and report rather than widening the grammar if:

1. structural signature refinement disagrees with the retained state relation;
2. characteristic formulas require action names;
3. the derived universe changes results for reasons other than duplicate
   representative removal;
4. formula generation becomes the primary object rather than a certificate
   layer;
5. a fixture result is presented as general modal completeness.

## Public Compression

A finite behavioral comparison basis can be generated from the behavior types
realized in the audited systems. Positive forcing formulas then provide
checkable certificates for the resulting bounded refinement relation. The
result remains relative to the positive atom grammar, horizon, and audited
system family.
