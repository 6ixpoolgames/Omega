# Alpha-Omega Foundation Protocol v0

Status: preregistered executable and theorem-spine protocol

Date: 2026-08-01

Parent handoff:
`docs/ALPHA_OMEGA_THEORY_PROPOSAL_HANDOFF_V0.md`

## Question

Can one finite, presentation-audited construction derive:

```text
oriented path laws;
residual continuation laws;
support-only reachability and viability;
statistical directional asymmetry;
candidate process feature profiles;
and the complete May-realization compatibility object
```

without selecting:

```text
a privileged observer;
a privileged candidate-process boundary;
a preferred maximal compatible face;
a valuer threshold;
or a moral objective?
```

## Status Discipline

This is a foundation sprint, not a moral derivation.

The retained result may establish a reusable mathematical body for later
Alpha-Omega work. It may not promote a process feature, entropy statistic,
compatibility face, or persistence fact directly to value or standing.

## Standard Mathematical Homes

The implementation should reuse the following established machinery:

```text
finite controlled Markov kernels:
  exact rational path probabilities;

finite labelled transition systems:
  support projection, bounded reachability, and robust viability;

path-space reversal:
  statistical comparison of a forward path law with a reversed comparison law;

simulation and bisimulation:
  one-sided and two-sided presentation contracts;

finite-state controllers:
  endogenous record and policy dependence;

presheaves on finite subsets / abstract simplicial complexes:
  realization fibers and their downward-closed support.
```

No general coalgebra library, general category implementation, modal
mu-calculus, or rule-universal ontology is required.

## Supplied Data

The finite adapter supplies:

```text
exact states;
actions;
an exact rational controlled transition kernel;
initial distributions;
a selected orientation experiment;
a reverse-path comparison convention;
state observations or atoms;
candidate finite-state controller presentations;
candidate realization predicates;
and any declared safe or recovery sets used by a fixture.
```

The orientation experiment is a parameter. It may return a null directional
profile.

The reverse comparison is part of the experiment and must be reported. No
single reverse-process convention is claimed to be universal.

## Formal Theorem Spine

Add a small Lean foundation namespace with no new moral vocabulary.

### Support blindness

For two action-labelled support relations on the same state and action types,
pointwise support equivalence must preserve:

```text
may predecessor;
robust same-action predecessor;
support reachability;
and support viability.
```

This theorem explains why transition weights cannot be recovered by the
existing support-only stack.

### Functional lens

A functional presentation has:

```text
forward:
  every exact step maps to a presented step;

back:
  every presented step from an image state lifts to an exact step.
```

Together with predicate respect, prove equivalence for:

```text
one-step diamond;
one-step box;
finite path existence;
and finite-path reachability of a predicate.
```

Forward alone is a simulation result. Forward plus back is the retained
two-sided fragment. It is not called a full modal or fixed-point invariance
theorem.

### Realization fibers

For a witness-to-candidate incidence relation, define:

```text
Real(G) = witnesses realizing every candidate in G.
```

Prove:

```text
G subset H -> Real(H) subset Real(G);
MayCompatible(H) -> MayCompatible(G).
```

The finite executable layer must retain the witnesses, not only the nonempty
support.

## Fixture Ladder

### Directional fixtures

Retain:

```text
directionally null reversible process;
biased reciprocal-support cycle;
finite-horizon probabilistic nonreturn;
policy-induced functional contraction;
support-asymmetric absorbing control.
```

The absorbing case is a diagnostic control. It is not a requirement for
Alpha-Omega construction.

### Support-blindness pair

Use two kernels with:

```text
identical action-labelled support;
different transition probabilities;
identical exhaustive support-derived observables;
different path-reversal divergence.
```

### Presentation fixtures

Retain:

```text
exact relabeling;
bisimilar duplicate-state quotient;
forward failure that erases an exact transition;
back failure that fabricates a presented transition;
atom-respect failure;
and a support-bisimilar projection that hides weighted directional grain.
```

The last fixture must be reported as a limitation of support bisimulation, not
as a failure of bisimulation on its declared grammar.

### Candidate-process fixtures

Separate:

```text
passive pattern;
effectful memoryless controller;
record-sensitive finite-state selector;
and presentation-injected agent label.
```

Return a feature profile. Do not return `valuer = true`.

### Omega fixture

Reuse the generated shared-action hollow triangle:

```text
each candidate singleton has witnesses;
each pair has at least one common witness;
the triple has none.
```

Retain the full family-to-witness table. Add an exact duplicate candidate
presentation and verify that quotienting by finite realization signature leaves
the decorated Omega object unchanged.

This quotient is licensed only inside the v0 fixture, where a candidate is
defined entirely by its complete finite incidence column. Equal bounded
behavior, equal sampled witnesses, or equal current output must not be used to
merge richer operational processes.

## Verdict Classes

```text
retained:
  all theorem targets compile, fixtures pass, and kill conditions remain false;

partial:
  the mathematical interfaces land but one declared fixture or formal theorem
  remains open;

rejected:
  a kill condition fires or the construction requires a privileged boundary or
  moral declaration.
```

## Acceptance Criteria

The sprint is retained only if:

1. Lean builds with no `sorry`, `admit`, or new axiom.
2. Exact rational finite kernels validate every state-action distribution.
3. Residual continuation laws normalize to one.
4. The support-blindness pair matches every declared support observable while
   separating path-law directionality.
5. Functional-lens negative controls fail the intended missing clause.
6. Candidate-process controls distinguish causal effect from endogenous record.
7. The Omega support is downward closed.
8. Restriction identity and composition checks pass.
9. Pairwise compatibility does not imply joint compatibility in the retained
   witness.
10. Exact duplicate candidate presentations do not change the quotient
    realization object.
11. No maximal face is selected as Capital Omega.
12. Focused tests, Ruff, Lean, and `git diff --check` pass.

## Kill Conditions

Stop and audit if:

```text
directionality changes solely because path reversal is inconsistently defined;

support-only machinery distinguishes equal supports;

transition weights are silently discarded before the directional comparison;

a functional presentation is called bisimilar without atom respect, forward,
and back clauses;

an injected label creates candidate-process evidence;

realization fibers are replaced by a declared compatibility graph;

duplicate candidate presentations inflate Omega;

pairwise compatibility is treated as joint compatibility;

one maximal face is chosen without an additional rule;

or any directional, persistence, compatibility, or entropy result is described
as value, standing, personhood, or moral license.
```
