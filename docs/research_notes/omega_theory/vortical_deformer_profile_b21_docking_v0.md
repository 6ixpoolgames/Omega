# Vortical Deformer Profile / B2.1 Docking v0

Status: docking note / terminology guardrail  
Scope: loop-closing deformer profiles, adaptive corridors, and recovery loss  
Claim boundary: not agency, not selfhood, not consciousness, not valuerhood, not moral standing, not value, not Omega validation

## Purpose

Older vortex/singularity language has been useful as a generator, but too loose for claims. B2.1 gives a colder way to restate the live part:

```text
an action-observation-update loop is relevant when it changes what
continuation can be maintained.
```

The deformer profile should therefore dock to:

```text
adaptive kernel membership;
observation/update soundness;
feedback advantage;
reflexive maintenance;
recovery or nonrecoverable contraction of correction capacity.
```

## What B2.1 Adds

B2.1 separates loop closure from sound loop closure:

```text
sound loop:
  observation/update keeps live models that could have produced the evidence.

phantom loop:
  update deletes the true model and then certifies only the false remainder.
```

That means:

```text
loop closure alone is not agency;
loop closure alone is not safety;
loop closure alone is not value.
```

The loop must preserve the distinctions it uses to maintain the corridor.

## Recovery Dock

The recovery frame adds an additional discriminator:

```text
same task success;
same apparent loop closure;
different recoverability of the correction register.
```

That is the precise home for the `self-lobotomy` pattern. A loop can continue operating while nonrecoverably destroying the register that would allow later correction.
