# Operational Causal Diamond and Reflexive Deformation Modes v0

Status: speculative agency-layer design note
Scope: agency-realization candidates, causal-diamond tests, deformation-mode detectors
Claim boundary: not Alpha, not value, not valuerhood, not identity, not agency detection, not Omega validation

## Purpose

This note records a candidate agency-layer direction after the effective-layer
reorientation.

The key consolidation is:

```text
The operational causal diamond should be the primary agency-layer candidate
object. Black-hole, vortex, caustic, wormhole, horizon, and ergoregion
analogies should be interpreted as qualitative regimes or measurements of that
object, not as coequal foundations.
```

This keeps the speculative geometry useful without promoting metaphor into
ontology.

## Layer Placement

This belongs in the agency-realization layer:

```text
Alpha:
  relation, distinction, asymmetry.

Continuation:
  reachability, viability, recovery, observed languages, robust profiles.

Agency:
  controllable-observable loops, feedback advantage, reflexive maintenance,
  presentation-stable deformation profiles.

Valuer / Gradient Ethics:
  protected joint-continuation effects and anti-collapse constraints.
```

The causal diamond is not value. It is not valuerhood. It is not Alpha. It is a
candidate effective object for agency-like process realization.

## Three Top-Level Axes

The current compressed geometry uses three axes:

```text
D:
  deformation geometry or leverage.

C:
  closure depth.

J:
  joint-continuation effect.
```

Older metaphors can be sorted inside this triple.

### Deformation geometry

These describe what a mode does to future continuation cones:

```text
focusing / caustic:
  many histories converge into a smaller macro-outcome family.

cone tilt / ergoregion:
  nearby processes retain alternatives, but feasible continuations are biased.

shortcut / wormhole:
  viable control distance between basins is reduced.

horizon:
  no-return boundaries are created or removed.

rank or topology transition:
  dimension, connectivity, or order structure of the viable continuation set
  changes.
```

### Closure depth

Closure is not one Boolean coordinate. It should distinguish:

```text
reactive closure:
  present input changes present response.

feedback closure:
  consequences change later responses.

maintenance closure:
  feedback preserves a declared continuation.

reflexive closure:
  feedback preserves the mechanism that performs the maintenance.

model-mediated closure:
  an internal predictive state alters correction before failure.
```

This separates a passive response, thermostat, adaptive controller,
self-maintaining process, and model-mediated process.

### Joint-continuation effect

Use this term rather than "valence" at the current layer.

This axis records whether the mode:

```text
expands;
preserves;
redistributes;
concentrates;
or destroys
```

the independently maintainable continuation structure of other processes.

Ethical valence is a later Gradient Ethics interpretation of this effect, not
the agency-layer measurement itself.

## Operational Causal Diamond

For a candidate mode `z` and horizon `H`, define informally:

```text
PastObs_H(z):
  substrate variables or events capable of affecting z's future state.

FutureInfluence_H(z):
  continuation facts whose distribution can be changed by z.

OperationalDiamond_H(z):
  PastObs_H(z) intersect FutureInfluence_H(z).
```

The geometry becomes agency-relevant only when the overlap closes through time:

```text
z_t
  -> future consequences
  -> later observations
  -> z_{t+1}.
```

A raw influence-response overlap is too weak. Reactive physical systems can
have broad causal diamonds. The agency-layer candidate needs feedback
essentiality and maintenance tests.

## Control-Theoretic Interpretation

The operational diamond has a close control-theoretic analogue:

```text
controllability:
  actions can affect future states or profiles.

observability:
  consequences can be detected at the interface.

controllable-observable overlap:
  the part of the process that can participate in a feedback loop.
```

For finite nonlinear systems, possible analogues include:

```text
reachable partitions;
observable equivalence classes;
policy-to-observation Hankel structure;
causal-state quotients;
bisimulation-style quotients.
```

A high-influence mode with no observability cannot close a consequence-sensitive
loop. A high-observability mode with no control cannot direct continuation. A
controllable-observable mode that does not preserve its own control channel is
a controller candidate, not yet a reflexive agency candidate.

## Candidate Agency Test

A cold name is preferable to "agentic singularity."

Use:

```text
OperationalCausalDiamond
ReflexiveDeformationMode
CriticalDeformationMode
```

and reserve "vortex" or "black-hole-like" language for interpretation.

A candidate mode qualifies only if it passes a sequence like:

```text
1. Leverage:
   ablation of the mode changes continuation geometry.

2. Operational diamond:
   the mode lies on a recurrent controllable-observable loop.

3. Feedback essentiality:
   live feedback preserves continuation that matched open-loop replay cannot.

4. Reflexive maintenance:
   the mode preserves the future availability of its own
   observation-selection-action channel.

5. Structural criticality:
   loss of the mode changes rank, topology, viable-kernel membership, or
   independent-target structure, not merely a scalar value.

6. Presentation stability:
   the mode or its effective profile survives sound re-presentation.
```

The decisive test is:

```text
Does a live controllable-observable loop preserve a continuation profile that
matched open-loop replay cannot, while also preserving the future availability
of that loop?
```

If yes, the agency-layer candidate has a non-cheap technical core. If no, the
geometry collapses back into ordinary causal influence.

## Spectral Methods

Previous spectral work should be read as detector instrumentation, not agency
definition.

The proper workflow is:

```text
intervention/deformation operator
  -> spectral or SVD candidate modes
  -> causal diamond test
  -> live-versus-replay test
  -> self-maintenance ablation
  -> presentation robustness.
```

Spectral/SVD methods can find high-leverage directions, low-dimensional
compressions, and dominant correlations. They do not discover agency by
themselves.

The earlier spectral result should remain bounded:

```text
spectral/SVD = candidate discovery
not agency detection.
```

Important counterexamples to include in future pilots:

```text
large singular value without feedback closure;
feedback closure without reflexive maintenance;
recurrence without control;
self-maintenance with modest leverage;
passive driven vortex with clean low-dimensional spectral mode.
```

## Joint Independence Profile

Raw "rank" is not yet safe. Rank of what?

Possible notions include:

```text
matrix rank of policy-to-outcome influence;
number of distinguishable continuation targets;
dimension of a controllable subspace;
width of a recovery lattice;
size of an independent target family;
rank of a matroid of non-substitutable continuation facts.
```

The safer near-term object is:

```text
joint independence profile over continuation targets.
```

Informally, a family of continuation targets is independent when no member is
recoverable or inferable from the others under the admitted presentations and
policy classes.

A destructive mode may reduce the independent continuation profile of other
processes even while preserving or expanding its own control. Gradient Ethics
would later interpret irreversible contraction of protected independent
continuation as normatively significant, but this note does not make that
ethical claim.

## Suggested Null Battery

Future pilots should use prespecified examples rather than tune the definition
after seeing outputs.

Candidate null battery:

```text
passive responsive particle;
stable attractor;
driven recurrent cycle;
thermostat;
adaptive controller;
self-restoring controller;
distributed cooperative controller;
dominant horizon-producing controller.
```

Expected broad pattern:

```text
passive systems:
  may score on leverage or recurrence; fail feedback advantage.

thermostat:
  feedback advantage; weak or absent reflexive maintenance.

self-restoring controller:
  feedback advantage plus reflexive maintenance.

dominant controller:
  high deformation and closure; negative joint-continuation effect.

cooperative controller:
  maintained closure with neutral or positive joint-continuation effect.
```

## Formal Targets After Pilot

Good theorem candidates after the pilot surface stabilizes:

```text
persistence does not imply feedback essentiality;

feedback essentiality does not imply reflexive maintenance;

a dominant singular mode of a deformation operator does not imply agency;

local step witnesses do not imply one coherent closed-loop process;

sound presentation transport preserves an operational-causal-diamond profile
only under explicit realizability and reflection assumptions.
```

These are strictness and transport theorems. They should precede any positive
agency or valuerhood claim.

## Non-Claims

This note does not claim:

```text
agency has been defined;
agency has been detected;
causal diamonds are valuers;
spectral modes are agents;
vortices are selves;
black-hole-like domination is agency;
joint-continuation effect is moral valence;
value follows from control;
Omega has been validated.
```

The current claim is only:

```text
the operational causal diamond is a promising agency-layer candidate object
because it separates leverage, closure depth, and joint-continuation effect
while keeping spectral methods in a detector role.
```
