# Valuer Profile And Comparative Patienthood v0

Status: conceptual scaffold / claim-boundary note  
Scope: patienthood-relevant continuation profiles and comparison cautions  
Claim boundary: not moral standing, not valuerhood, not personhood, not rights, not aggregation, not value detection, not Omega validation

## Purpose

The recovery weld makes one thing more visible: destroying a correction register is different from merely changing a local state. That is patienthood-relevant, but it is not yet patienthood.

This note keeps the distinction explicit.

## Working Shape

A future valuer/patienthood profile should likely be multi-axis:

```text
continuation capacity:
  can the process maintain a declared profile?

correction capacity:
  can it preserve or recover distinctions needed for later revision?

experience/contact capacity:
  can it be affected by value-relevant distinctions?

agency/control capacity:
  can it influence its own continuation profile?

lineage capacity:
  can the relevant profile persist through time and presentation changes?

joint compatibility:
  can its continuation coexist with other protected profiles?
```

None of these axes alone is moral standing.

## Comparative Patienthood

The tractable near-term object is comparative, not absolute:

```text
Profile A preserves more patienthood-relevant capacity than Profile B
relative to a declared register and recovery frame.
```

This is not the same as:

```text
A has more moral worth than B.
```

Comparative profile facts are inputs to a later standing theory. They do not supply that theory.

## Apoptosis Stress Test

The apoptosis-style objection remains a guardrail:

```text
local nonrecoverable contraction can be compatible with larger joint
continuation.
```

Therefore:

```text
local nonrecoverable contraction != harm
```

until the joint profile and protected standing relation are declared.

## Current Safe Claim

The current safe claim is:

```text
nonrecoverable loss of a declared correction or continuation capacity is a
patienthood-relevant profile fact.
```

It is not:

```text
the harmed subject has been identified.
```

## Next Pressure

The next tractable theorem would be a joint-profile witness:

```text
two transitions have the same local task success;
one preserves joint correction capacity;
the other destroys a registered correction coordinate nonrecoverably.
```

That would still be below moral standing, but it would make the patienthood-relevant profile surface harder to dismiss as ordinary task failure.
