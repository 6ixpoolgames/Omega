# Finite Deformer Profile Checkpoint v0

Status: consolidation checkpoint
Scope: operational-causal-diamond pilots, deterministic/stochastic deformer instrumentation
Claim boundary: not agency, not identity, not value, not valuerhood, not Omega validation, not empirical transition-model validation

## Purpose

This note compresses the current deterministic and stochastic agency-diamond
pilot stack into one bounded claim:

```text
The repository now has a finite deformer-profile instrument.
```

That does not mean it detects agents. It means the harness can measure when a
declared mode changes a future-facing continuation profile in small exact
finite systems, while retaining counterexamples showing that common proxies do
not determine that profile.

The current profile is useful because it separates:

```text
deformation / leverage:
  changing or ablating the mode changes continuation facts;

closure depth:
  live feedback beats matched open-loop replay, and sometimes preserves the
  future availability of the observation-selection-action channel;

joint-continuation effect:
  the same own-maintenance profile can coincide with neutral, positive, or
  negative effects on a declared joint-safe surface.
```

This is still an effective-layer instrument. It is not Alpha. It is not the
Gradient Ethics target. It is a finite bridge for asking whether a candidate
mode actually shapes continuation rather than merely receiving an evocative
label.

## Exact Current Claim

The checked claim is:

```text
In retained synthetic finite controlled systems, the operational-causal-diamond
profile separates continuation-deforming structure from several tempting
proxies, and this separation survives generated, held-out, cross-substrate, and
exact-rational stochastic stress tests.
```

The current claim is not:

```text
this profile is sufficient for agency;
this profile identifies a self, valuer, or object;
this profile has moral standing;
this profile transfers to empirical systems;
this profile validates Omega.
```

## Current Profile Surface

The deterministic pilot measures:

```text
control reach:
  whether available actions alter reachable future profiles;

observable control:
  whether those action-distinct future profiles are exposed at the declared
  observation interface;

feedback advantage:
  live observation-conditioned policy performance minus matched open-loop
  replay performance;

reflexive maintenance:
  preservation of the declared target together with the future availability of
  the control-observation channel;

joint-continuation effect:
  live policy effect on a declared shared/joint-safe continuation surface;

presentation transport:
  whether relabeling, identity presentations, and quotient controls preserve
  or reject the profile as expected.
```

The stochastic pilot replaces Boolean success with exact-rational
finite-horizon probabilities:

```text
live maintenance probability;
best open-loop replay probability;
feedback advantage;
reflexive maintenance probability;
joint-continuation effect probability;
strong-lumpability presentation coherence;
robust worst-case feedback over a small ambiguity set.
```

## What The Controls Rule Out

The current controls rule out several cheap readings.

| Tempting Proxy | Why It Fails |
| --- | --- |
| Recurrence | Recurrent systems can have no feedback advantage. |
| Control reach | Action-distinct futures can exist without live feedback outperforming matched open-loop replay. |
| Feedback advantage | Feedback can be positive without reflexive maintenance of the channel. |
| High live success | High live maintenance probability can occur with zero feedback deformation. |
| Stochasticity | Nontrivial transition probabilities do not imply controllable deformation. |
| One scalar success score | Matched live maintenance can have different joint effects. |
| Average-case feedback | Average feedback advantage can disappear under worst-case ambiguity. |
| One-step support / coarse presentation | Non-lumpable presentations can splice incompatible hidden stochastic representatives. |
| Source grammar | The profile is not confined to one small deterministic grammar; it appears in Boolean, grid, resource, deterministic, and stochastic surfaces. |
| Complex spectral phase | A driven cycle can have complex nominal live-policy spectrum without control, while reflexive maintenance can occur without complex phase. |

This is the main positive content of the checkpoint. The profile is not merely
a name for “successful system.” It has nulls, strictness controls, ablation
controls, and calibration curves.

## Necessary Versus Useful Controls

The likely necessary controls for any future deformer-profile claim are:

```text
1. false-positive controls:
   recurrence, control, stochasticity, and high live success must not be
   accepted as sufficient.

2. ablation sensitivity:
   changing observation, policy, action dynamics, channel repair, or joint
   surface must alter the corresponding profile axis when that axis is claimed.

3. live-vs-replay comparison:
   feedback claims must be compared against matched open-loop replay.

4. robust ambiguity check:
   average-case advantage must be separated from worst-case advantage when
   perturbation ambiguity is declared.

5. presentation coherence:
   process truth must require coherent path lifting in deterministic systems
   and strong lumpability or an explicit non-Markov model in stochastic systems.

6. non-predeclared search:
   at least one run surface must derive labels and clusters after evaluation,
   not encode expected outcome labels as fixture facts.
```

Useful but not individually necessary controls:

```text
cross-substrate source grammars;
calibration / phase sweeps;
baseline-collision tournaments;
relabel / decoy invariance;
quotient negative controls;
large held-out seed counts.
```

Those useful controls increase confidence that the instrument is not just
recovering one handcrafted fixture family.

## Deformer Reading

The safest current definition is operational:

```text
A declared mode is a finite continuation deformer when interventions or
ablations on that mode change a declared future-facing continuation profile
under an explicit finite realization, and when simple proxies are shown not to
determine that change.
```

This definition is deliberately lower than agency. A deformer can be passive,
externally driven, beneficial, destructive, or merely locally influential. The
agency-layer question would require additional endogeneity, feedback
essentiality, reflexive maintenance, and transport coherence. The current
checkpoint does not claim those are jointly sufficient.

## What Remains Fragile

The current finite deformer profile is still fragile in several ways:

```text
synthetic systems:
  all positive evidence is finite and generated.

declared targets and surfaces:
  targets, safe sets, observations, scenarios, and joint surfaces remain
  realization-supplied.

classification rules:
  labels are computed from profiles, but the profile axes are still designed by
  us.

strong sufficiency:
  the harness shows separation and deformation, not an iff theorem for
  deformerhood.

empirical adapters:
  no real transition model, sensor model, or intervention model has been
  validated.
```

This fragility is acceptable for the current checkpoint because the result is
instrumental: the project has a probe with nulls and pressure tests, not a
complete ontology.
