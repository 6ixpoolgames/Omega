# Reward Is Not Utility / Agency Profile Guardrail v0

Status: guardrail note  
Scope: reward, utility, task success, agency profiles, and correction-capacity loss  
Claim boundary: not utility theory, not agency detection, not value, not valuerhood, not moral standing, not identity, not Omega validation

## Purpose

The recovery-frame witnesses make a familiar failure mode explicit:

```text
the task can still be scored as successful while the system destroys the
capacity needed for later correction.
```

That is why reward, utility, task success, and agency profile must remain separated.

## Separations

Reward:

```text
an externally supplied training or scoring signal.
```

Task success:

```text
a declared predicate or benchmark outcome.
```

Utility:

```text
a decision-theoretic representation of preference or valuation under
additional assumptions.
```

Agency profile:

```text
control, feedback, maintenance, reflexivity, and joint-effect coordinates.
```

Correction capacity:

```text
the registered ability to preserve or recover distinctions needed for future
revision, comparison, or repair.
```

None of these collapses into another by definition.

## Self-Lobotomy Pattern

The internal alias remains useful:

```text
self-lobotomy
```

Formal reading:

```text
same task success;
nonrecoverable correction-register collapse.
```

This is not automatically low utility, moral harm, or patienthood violation. It is a typed warning that the reward/task surface is too coarse to certify future correction capacity.

## Guardrail

Do not infer:

```text
high reward -> utility preservation
high task success -> correction capacity preservation
behavioral competence -> agency
closed loop -> sound update
deformer score -> value
```

Each arrow requires a declared bridge theorem or certification contract.

## Next Pressure

The next useful formal target is a controlled-system strictness witness:

```text
two policies have the same task-success profile;
one preserves the correction register;
the other nonrecoverably collapses it.
```

The current `RecoveryFrame` example lands the abstract witness. A later operational-causal-diamond version should connect it to action/observation loop profiles.
