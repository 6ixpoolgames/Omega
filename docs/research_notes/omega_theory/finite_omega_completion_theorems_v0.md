## 0. Purpose

This note gives the first theorem-grade sandbox for the Omega formalism.

It does **not** prove that Omega exists in the physical world. It does **not** prove that current Future Field Atlas results instantiate proto-valuers, valuers, agency, identity, value, or compatibility.

It proves small finite facts about compatibility completions:

```text
1. finite maximal admissible completions exist when the admissible family is nonempty;
2. a greatest completion need not exist;
3. pairwise compatibility does not imply joint compatibility;
4. marginal continuation does not imply joint-field compatibility;
5. finite completions are computable by exhaustive enumeration in principle.
```

The goal is to harden the completion layer before attempting theorem-grade proto-valuerhood.

## 2. Basic definitions

### Definition 2.1: Finite candidate set

Let `T` be a finite set.

Elements of `T` are called **candidate units**. A candidate unit may later represent a trajectory, process-bundle token, fiber, or designated future-bearing component, but this note assigns no semantic status beyond membership in `T`.

### Definition 2.2: Candidate completion

A **candidate completion** is a subset:

```text
Y subset T.
```

Intuitively, `Y` is a proposed jointly admissible collection of future-bearing units.

### Definition 2.3: Admissibility predicate

An **admissibility predicate** is a function:

```text
Adm : P(T) -> {true, false}
```

where `P(T)` is the power set of `T`.

`Adm(Y)` means that `Y` satisfies the declared admissibility conditions for the layer being studied.

At the completion layer, admissibility may later include:

```text
recoverability;
non-erasure;
compatibility;
perturbation robustness;
identity-decay-null separation;
absence of systematic irreversible destruction of distinction-content.
```

This note does not specify those internal criteria. It studies the completion structure induced by any declared `Adm`.

### Definition 2.4: Admissible family

The admissible family generated by `Adm` is:

```text
A = { Y subset T : Adm(Y) }.
```

This note assumes `A` is nonempty unless otherwise stated.

Often `emptyset in A`, but the proofs only require nonemptiness.

### Definition 2.5: Subset-maximal admissible completion

An admissible set `Y in A` is **subset-maximal** when there is no admissible strict superset:

```text
there does not exist Z in A such that Y proper-subset Z subset T.
```

### Definition 2.6: Omega completion family, finite case

The finite Omega completion family is:

```text
Omega_Fin(T, Adm) = Max_subset { Y subset T : Adm(Y) }.
```

Equivalently:

```text
Omega_Fin(T, Adm) = { Y in A : Y is subset-maximal in A }.
```

### Definition 2.7: Greatest admissible completion

A set `G in A` is **greatest** when every admissible set is contained in it:

```text
for all Y in A, Y subset G.
```

A greatest admissible completion, if it exists, is unique.

A subset-maximal completion need not be greatest.

This distinction is central: Omega should not be assumed to be a single greatest object unless additional structure proves it.

## 3. Theorem 1: finite maximal completions exist

### Statement

Let `T` be finite and let `A = {Y subset T : Adm(Y)}` be nonempty. Then:

```text
Omega_Fin(T, Adm) is nonempty.
```

That is, at least one subset-maximal admissible completion exists.

### Proof

Because `T` is finite, its power set `P(T)` is finite. Therefore `A`, as a subset of `P(T)`, is finite.

Since `A` is nonempty, choose any `Y_0 in A`.

If `Y_0` has no admissible strict superset, then `Y_0` is subset-maximal and we are done.

Otherwise choose an admissible strict superset `Y_1` of `Y_0`.

Repeat this process. Each step strictly increases cardinality:

```text
|Y_0| < |Y_1| < |Y_2| < ...
```

Since all sets are subsets of finite `T`, the cardinality can increase at most `|T|` times. Therefore the process terminates at some admissible set `Y_n` with no admissible strict superset.

Thus `Y_n` is subset-maximal.

So `Omega_Fin(T, Adm)` is nonempty. ∎

### Interpretation

In a finite toy setting, if any admissible completion exists at all, then at least one maximal admissible completion exists.

This is a minimal theorem-grade justification for using maximal completion language in finite Future Field Atlas approximants.

It does not imply uniqueness.

## 4. Theorem 2: a greatest completion need not exist

### Statement

There exist finite `T` and admissibility predicate `Adm` such that maximal admissible completions exist but no greatest admissible completion exists.

### Construction

Let:

```text
T = {a, b, c}
```

Define admissibility by:

```text
Adm(Y) iff Y subset {a, b} or Y subset {a, c}.
```

Equivalently, the admissible sets are:

```text
emptyset
{a}
{b}
{c}
{a,b}
{a,c}
```

The set `{b,c}` is not admissible, and `{a,b,c}` is not admissible.

### Proof

The sets `{a,b}` and `{a,c}` are admissible.

Neither has an admissible strict superset:

```text
{a,b} proper-subset {a,b,c}, but {a,b,c} is not admissible.
{a,c} proper-subset {a,b,c}, but {a,b,c} is not admissible.
```

So both `{a,b}` and `{a,c}` are subset-maximal admissible completions.

A greatest admissible completion `G`, if it existed, would need to contain both `{a,b}` and `{a,c}`. Therefore it would need to contain:

```text
{a,b,c}.
```

But `{a,b,c}` is not admissible. Hence no greatest admissible completion exists. ∎

### Interpretation

Even in a three-element finite system, Omega-like completion structure may be a **family** of maximal completions rather than a single greatest object.

This supports the current formulation:

```text
Omega is generally a space/family of maximal admissible compatibility completions,
not a presumed greatest fixed point.
```

A greatest object may still exist under extra assumptions, but it must be proven as a special case.

## 5. Theorem 3: pairwise compatibility does not imply joint compatibility

### Definition 5.1: Pairwise admissibility

For a finite set `T` and predicate `Adm`, say a set `Y subset T` is **pairwise admissible** if every two-element subset of `Y` is admissible:

```text
for all {x,y} subset Y with x != y, Adm({x,y}).
```

### Statement

There exist finite `T` and `Adm` such that every pair in `T` is admissible, but `T` itself is not admissible.

### Construction

Let:

```text
T = {a, b, c}
```

Define:

```text
Adm(Y) iff |Y| <= 2.
```

Thus all singleton and pair subsets are admissible, but the triple is not.

### Proof

Every two-element subset of `T` has cardinality `2`, so every pair is admissible:

```text
Adm({a,b}) = true
Adm({a,c}) = true
Adm({b,c}) = true
```

But:

```text
|{a,b,c}| = 3 > 2
```

so:

```text
Adm({a,b,c}) = false.
```

Therefore pairwise admissibility does not imply joint admissibility. ∎

### Interpretation

Compatibility is generally n-ary and context-sensitive.

A future-bearing unit may be compatible with `B` and compatible with `C` separately, while the joint collection `{A,B,C}` fails under shared capacity, joint-field restriction, resource conflict, or higher-order interference.

This is why the completion layer must reason over sets/families, not just pairwise edges.

## 6. Theorem 4: marginal continuation does not imply joint-field compatibility

### Setup

Let two component fields have marginal supports:

```text
A = {a1, a2}
B = {b1, b2}
```

The product future field is:

```text
A x B = {
  (a1,b1),
  (a1,b2),
  (a2,b1),
  (a2,b2)
}.
```

Let a coupled future field have joint support:

```text
J = {
  (a1,b1),
  (a2,b2)
}.
```

### Marginal projections

The A-marginal of `J` is:

```text
pi_A(J) = {a1, a2} = A.
```

The B-marginal of `J` is:

```text
pi_B(J) = {b1, b2} = B.
```

Thus both component marginals are fully retained:

```text
A_marginal_retention = 1
B_marginal_retention = 1
```

### Joint support retention

But joint support retention is:

```text
|J| / |A x B| = 2 / 4 = 1/2.
```

The joint combinations:

```text
(a1,b2)
(a2,b1)
```

are absent.

### Statement

Full marginal retention does not imply full joint support retention, and therefore does not imply joint-field compatibility or non-erasure.

### Proof

The example above satisfies:

```text
pi_A(J) = A
pi_B(J) = B
```

so both marginals are fully preserved.

However:

```text
J proper-subset A x B.
```

Therefore at least one joint distinction available in the product field is absent in the coupled field. In this construction, two product-available joint combinations are absent.

Thus marginal continuation is compatible with strict joint-field restriction.

So marginal continuation alone cannot imply compatibility, non-erasure, or joint future-field preservation. ∎

### Interpretation

This theorem formalizes a key Future Field Atlas lesson:

```text
marginal continuation is not compatibility.
```

A coupled operator may preserve A/B marginal reachability while restricting the joint field. Whether that restriction is compatible, erasing, capturing, supportive, or benign requires additional admissibility criteria.

## 7. Theorem 5: finite completion families are computable by exhaustive enumeration

### Statement

Let `T` be finite and let `Adm` be decidable on every subset of `T`. Then `Omega_Fin(T, Adm)` is computable by exhaustive enumeration.

### Proof

Since `T` is finite, `P(T)` is finite with size:

```text
|P(T)| = 2^{|T|}.
```

Evaluate `Adm(Y)` for every `Y subset T`. This constructs the finite admissible family:

```text
A = {Y subset T : Adm(Y)}.
```

For each `Y in A`, check whether there exists `Z in A` such that:

```text
Y proper-subset Z.
```

If no such `Z` exists, include `Y` in `Omega_Fin(T, Adm)`.

This procedure terminates after finitely many checks and returns exactly the subset-maximal admissible sets. ∎

### Interpretation

Finite Omega completion structure is not merely metaphorical. In small finite systems, it can be computed exactly once the admissibility predicate is declared.

This does not make the computation cheap. Exhaustive enumeration is exponential in `|T|`. But it establishes a baseline exact method for tiny systems and formal verification.

## 8. Finite algorithm sketch

```text
input:
  finite T
  decidable Adm(Y)

A = []
for each Y subset T:
  if Adm(Y):
    add Y to A

Omega = []
for each Y in A:
  maximal = true
  for each Z in A:
    if Y proper-subset Z:
      maximal = false
      break
  if maximal:
    add Y to Omega

return Omega
```

This is a theorem scaffold, not a recommended large-scale empirical algorithm.

Future scalable approximations may use search, SAT/SMT encodings, branch-and-bound, graph algorithms under special assumptions, or learned heuristics. But the exact finite object comes first.
