```text
proto-valuer-bearing dynamics propagate recoverably and non-erasingly without
systematic irreversible destruction of one another's distinction-content.
```

This is an organizing target, not an empirical result.

## 7. Main formal backdoors and current defenses

### 7.1 `Adm`

Risk:

```text
compatibility/completion criteria can hide the whole theory.
```

Defense:

```text
finite completion theorems treat Adm abstractly only as scaffolding;
future substantive claims must decompose Adm into recoverability, non-erasure,
compatibility, perturbation, null, and audit criteria.
```

### 7.2 `N_P`

Risk:

```text
identity-decay null can be too weak, too destructive, or chosen after the fact.
```

Defense:

```text
identity-decay null taxonomy;
null admissibility contract;
null shopping prohibition;
required null manifests and matching audits.
```

### 7.3 `M_Q`

Risk:

```text
distinction-content can smuggle relevance through arbitrary measures.
```

Defense:

```text
finite distinction measures menu;
observable predeclaration;
artifact reconstruction requirements;
measure claim boundaries.
```

### 7.4 `CompAudit`

Risk:

```text
compatibility-audited valuerhood can be made to fail or pass by audit choice.
```

Current defense:

```text
used only as a declared predicate in separation scaffolds.
```

Remaining need:

```text
compatibility audit taxonomy.
```

### 7.5 Thresholds

Risk:

```text
rho, eta, gamma, alpha, theta can be tuned after seeing results.
```

Defense needed:

```text
threshold predeclaration, sensitivity sweeps, and threshold manifest artifacts.
```
