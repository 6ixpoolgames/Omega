# Joint-Tier Reduction Audit Protocol v0

Status: preregistration / finite reduction-pressure audit
Scope: planted-null controls and scoped reduction attempts over recent joint-tier instruments
Claim boundary: not value, not standing, not agency, not population ethics, not plurality theory, not aggregation, not patienthood, not Omega validation

## Purpose

The recent joint-tier instruments now include:

```text
ensemble span;
relational composability;
joint recovery compatibility;
colonization / cross-scale viable refinement.
```

This protocol tests whether the instruments are flattering us. The audit is
deliberately adversarial: known reducible coordinates must reduce, and new
coordinates must survive at least the cheap reductions already available.

This pass skips the public contact artifact and does not open
`CompensationClaim` / NOLP. It is a calibration pass before NOLP.

## Verdict Classes

```text
calibrated
  planted nulls reduce and scoped reduction attempts return the preregistered
  conservative verdicts.

review
  a planted null fails to reduce, a reduction attempt contradicts the retained
  witness, or the harness cannot express the audit target cleanly.
```

For individual reduction attempts:

```text
reduces
  the tested coordinate is already a declared control or existing profile
  quantity.

survives_simple_reduction
  the retained witness survives the named cheap reduction, with broader
  reductions still open.

bridge_not_independent_axis
  the target is useful but should be treated as a bridge through existing
  registered data, not as a fresh independent axis.

open
  the right reduction target requires a theorem or interface not present in
  this pass.
```

## Planted Nulls

The planted-null controls are intentionally reducible:

```text
ensemble span:
  total_l1_amount reduces to the marginal summary.

relational composability:
  compatible_pair_count reduces to the compatibility profile.

joint recovery compatibility:
  joint_missing_fact_count reduces to the recovery profile.

colonization axis:
  viable_state_count reduces to the control panel.
```

Kill condition:

```text
If any planted null does not return `reduces`, the whole joint-tier instrument
family is suspect and no further axis language is promoted.
```

## Reduction Attempts

### Relational Composability

Hypothesis:

```text
relational composability reduces to pure span plus cheap graph summaries.
```

v0 test:

```text
same full vector census;
same pure span;
same compatible-pair count;
same degree sequence;
different component structure.
```

Expected conservative verdict:

```text
survives_simple_graph_scalar_reduction
```

This blocks reduction to pair count or degree sequence only. It does not prove
independence from all graph summaries.

### Colonization Axis

Hypothesis:

```text
colonization reduces to control-panel quantities or simple scalar shadows of
the certified-chain structure.
```

v0 test:

```text
control panel equal;
scalar shadow equal;
order still separates.
```

Expected conservative verdict:

```text
survives_scalar_shadow_reduction_lens_debt_open
```

The sound-quotient / lens-lattice reduction remains open. This audit does not
pay the global lens-invariance debt.

### Joint Recovery Compatibility

Hypothesis:

```text
joint recovery compatibility factors as a registered coupling surface plus
declared recovery labels.
```

Expected conservative verdict:

```text
bridge_not_independent_axis
```

This is not a failure. It locates the instrument: joint recovery compatibility
is a recovery-grounded bridge, not a new coordinate competing with span or
colonization.

## Out Of Scope

This pass does not implement:

```text
CompensationClaim / NOLP verdicts;
patient-level ordering;
population value;
standing;
full lens invariance;
stochastic or quantum structure;
endogenous register / no-laundering;
large-deformer instruments.
```

## Public Compression

The joint-tier reduction audit asks whether the new instruments are flattering
us. Known reducible coordinates must reduce; relational composability must not
collapse to pair count or degree sequence; colonization must keep its lens debt
visible; joint recovery compatibility should be treated as a bridge through
coupling plus recovery, not as an independent axis.
