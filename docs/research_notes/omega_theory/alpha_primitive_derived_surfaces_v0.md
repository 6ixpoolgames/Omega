# Alpha Primitive-Derived Surfaces v0

Status: active formal note
Scope: Alpha-native structures derivable from relation, distinction, and asymmetry
Claim boundary: not consequence, dynamics, value, agency, valuerhood, or Omega validation

## Purpose

This note documents the first repair pass that derives more structure inside
`AlphaCore` without smuggling in adapter-level consequence or identity.

The new Lean files are:

```text
formal/lean/AlphaCore/PrimitiveApartness.lean
formal/lean/AlphaCore/PrimitivePath.lean
formal/lean/AlphaCore/PrimitiveSoundPresentation.lean
```

## What Alpha Supplies

An Alpha frame supplies:

```text
Rel  : X -> X -> Prop
Sep  : Dist -> X -> X -> Prop
Asym : Dist -> X -> X -> Prop
```

with the existing laws:

```text
Asym d x y -> Rel x y
Asym d x y -> Sep d x y
Sep d x x is impossible
Sep is symmetric
```

These primitives support more internal structure than mere noncollapse, but
they still do not supply evaluated consequence, adapter dynamics, value, or
agency by themselves.

## New Alpha-Native Surfaces

### Primitive apartness

```text
PrimitiveApart A x y :=
  exists d, A.Sep d x y
```

This is the Alpha-native distinguishability relation generated by primitive
separation.

It proves:

```text
primitive apartness is symmetric;
primitive apartness is irreflexive;
primitive apartness implies non-equality;
asymmetry witnesses imply primitive apartness;
primitive witnesses imply that the frame has primitive apartness;
identification collapse is equivalent to absence of primitive apartness.
```

### Primitive path

```text
PrimitivePath A x y :=
  Reach A x y
```

This treats `Rel` as the free relation-generated path structure. It is not yet
time, dynamics, or continuation in the adapter sense.

It proves:

```text
primitive paths are reflexive;
relations generate primitive paths;
primitive paths compose;
asymmetry witnesses generate both a primitive path and primitive apartness;
mutual primitive reach generates a primitive carrier candidate.
```

### Primitive-sound presentation

```text
PrimitiveSoundPresentation A present :=
  forall x y,
    present x = present y ->
      not (PrimitiveApart A x y)
```

This is the Alpha-native analogue of sound quotient discipline. A presentation
may merge only primitively inseparable relata.

It proves:

```text
primitive apartness blocks primitive-sound merging;
asymmetry-witness endpoints are invariant under primitive-sound presentations;
primitive nondegeneracy makes the constant presentation unsound;
primitive-preserving maps pull primitive-sound presentations back.
```

## Why This Matters

This gives Alpha more real work to do before adapters:

```text
Alpha derives primitive apartness;
Alpha derives relation-generated path candidates;
Alpha constrains primitive-sound presentation;
Alpha blocks primitive erasure before consequence contexts are introduced.
```

The key point is negative and structural:

```text
not every quotient, presentation, or coarse view is admissible even at the
primitive layer.
```

## What It Does Not Derive

Alpha still does not derive:

```text
evaluated consequence contexts;
comparison panels;
adapter dynamics;
safety predicates;
viability;
value;
valuerhood;
agency;
Omega-terminal structure.
```

The downstream bridge should remain:

```text
Alpha yields primitive apartness and path candidates.
Adapters expose some of that primitive structure as evaluated consequence and
continuation.
```

not:

```text
Alpha magically contains every consequence apparatus.
```
