# Phantom Recoverability Gate v0

Status: Lean theorem checkpoint / recovery-aware gate strictness witness  
Scope: corrupted recovery frame licensing an action refused by the true recovery-aware corridor  
Claim boundary: not harm, not rights, not moral standing, not deception theory, not agency, not identity, not value, not Omega validation

## Purpose

The recovery-aware corridor refuses actions whose successors nonrecoverably contract a declared recovery fact. This note records the corresponding strictness warning:

```text
a corrupted recovery frame can counterfeit recoverability and thereby license
what the true recovery-aware gate refuses.
```

This is the recovery-layer analogue of phantom viability and fake-update phantom safety.


recovery-aware licenses transport to true recovery-aware licenses.

## What It Shows

The recovery-aware gate is only as sound as the registered recovery frame:

```text
true frame:
  collapsed state is not recoverable.

phantom frame:
  collapsed state is counted as recovered by erasing the refuting distinction.

result:
  the phantom corridor admits a license the true corridor rejects.
```

That is the formal core of the "phantom recoverability meets the gate" warning.

## Register Adequacy Liability

The theorem also makes a general liability explicit:

```text
undeclared vulnerable structure is invisible to the gate;
overdeclared vulnerable structure can paralyze the floor;
corrupted declared structure can counterfeit safety.
```

This is not a defect in registry-first design. It is the price of auditability. The framework can enforce what is declared and certified; it cannot protect a fact that never enters the register, and it cannot trust a register whose recovery surface is corrupted.

## Interpretation

Safe reading:

```text
If a declared recovery fact is part of the corridor requirement, then the
recovery frame used to compute that requirement must itself be certified.
```

Unsafe overread:

```text
the theorem defines harm;
the theorem proves rights;
the theorem identifies a deceiver;
the theorem supplies moral standing.
```

Those remain out of scope.
