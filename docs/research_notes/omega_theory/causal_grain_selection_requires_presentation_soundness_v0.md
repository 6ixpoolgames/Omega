# Causal Grain Selection Requires Presentation Soundness v0

Status: guardrail note / adjacent-work docking  
Scope: causal-emergence or grain-selection claims used as presentations  
Claim boundary: not causal-emergence validation, not agency, not consciousness, not value, not moral standing, not Omega validation

## Purpose

Adjacent work often says that the right causal grain can carry more explanatory or intervention-relevant structure than a microscopic description. Omega can use that idea, but only under the existing presentation discipline.

The guardrail:

```text
high causal power at a coarse grain does not automatically make the grain
sound for the consequence facts being used.
```

## Omega Translation

A causal grain is a presentation:

```text
q : exact system -> coarse system
```

It may be useful, predictive, compact, or interventionally strong. That is not enough. If the grain is used to justify reachability, viability, recovery, agency-profile, or correction-register claims, it must satisfy the relevant reflection/soundness contract.

## Failure Modes

A coarse grain can:

```text
hide loss;
fabricate reachability;
fabricate viability;
merge consequence-separated states;
erase correction-register distinctions;
make phantom recoverability look real.
```

The B2.1 fake-update witness is the update-layer version of the same problem: an apparently useful information state can become unsafe when it excludes the true model.

## Safe Use

Causal grain selection is admissible only relative to a declared fact family:

```text
this grain preserves the facts it is being used to reason about.
```

Without that declaration, causal-emergence scores are detector coordinates, not certification.

## Nonclaims

This note does not claim:

```text
that causal emergence is false;
that micro descriptions are always superior;
that a high-level causal grain is ontologically privileged;
that causal power implies agency, value, standing, or consciousness.
```

It says only that Omega treats grain choice as a presentation-soundness problem.

## Next Pressure

A finite witness target:

```text
two coarse grains have matched predictive or causal-emergence score;
one preserves a declared recovery/correction fact;
the other hides or fabricates it.
```

That witness would connect causal-grain claims to the existing non-factorization and recovery-frame machinery.
