# Alpha Primitive Core v0

Status: Lean-checked primitive floor
Scope: relation, distinction, asymmetry

## Summary

Alpha is the standalone primitive floor for the project. It names the minimum
substrate-neutral structure:

```text
relation
distinction
asymmetry
```

Omega is downstream of Alpha. The older `OmegaCore` Lean stack remains useful,
but it is not Alpha's parent. It should be treated as support/recoverability
machinery to ingest, refactor, or translate after Alpha is established.

## Primitive Frame

`AlphaCore/Primitive.lean` defines:

```text
Frame:
  X:
    carrier

  Rel:
    relation over X

  Dist:
    distinction family

  Sep:
    separation predicate for distinctions

  Asym:
    asymmetry predicate typed over distinctions and endpoints
```

Required laws:

```text
Sep is irreflexive.
Sep is symmetric.
Asym implies Rel.
Asym implies Sep.
```

Checked consequences:

```text
asymmetry_implies_relation
asymmetry_implies_distinction
asymmetry_implies_not_same
hasAsymmetry_implies_alphaInstantiated
```

The last theorem is intentionally important: in this minimal frame,
asymmetry is load-bearing because every asymmetry witness already supplies a
relation witness and a distinction witness.

## Reachability Layer

`AlphaCore/Reachability.lean` adds graph reachability generated by relation.
This is not a new primitive; it is a derived relation-level structure.

Checked:

```text
reach_of_rel
reach_trans
reach_from_sink_eq
reach_irreversible_not_symmetric
```

The file also distinguishes:

```text
LocalNonreciprocal:
  relation x -> y without relation y -> x

ReachIrreversible:
  reachable x -> y without reachable y -> x

AsymOneWay:
  asymmetry x -> y without asymmetry y -> x
```

These are deliberately separate. Alpha does not collapse local asymmetry,
local nonreciprocity, and global reach irreversibility.

## Separation Examples

`AlphaCore/Examples.lean` checks tiny finite examples:

```text
distinction_without_asymmetry:
  a frame can contain distinctions without any asymmetry

asymmetry_not_reach_irreversibility:
  a local asymmetry can exist while the target reaches back to the source

reach_irreversibility_exists:
  one-way reachability exists in a tiny one-step chain

local_nonreciprocity_not_reach_irreversibility:
  a local one-way edge can still sit inside a globally returning cycle

tiny_alpha_instantiated:
  a minimal chain frame instantiates relation, distinction, and asymmetry
```

## Important Separations

Alpha does not define:

```text
recoverability
non-erasure
compatibility
completion
viability
value
valuerhood
identity
agency
Omega
```

Some of those may be derived later. Some are presentation-specific. The point
of this pass is to stop using downstream terms as primitive load-bearing
structure.

## Relationship To OmegaCore

`OmegaCore` currently contains the older support-level machinery:

```text
DistTrans
NormalLax distinction transport
finite completion scaffolds
finite Boolean and channel presentations
probabilistic channel enrichment
```

Those files remain valid checked work. They are not deleted or demoted to
irrelevance. The unification question is deferred:

```text
establish Alpha first;
then decide which OmegaCore pieces become Alpha presentations,
which become downstream Omega modules,
and which remain historical scaffolding.
```
