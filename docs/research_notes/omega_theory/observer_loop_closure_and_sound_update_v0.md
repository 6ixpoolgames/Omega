# Observer Loop Closure And Sound Update v0

Status: external-adjacency note / B2.1 interpretation bridge  
Scope: bounded observer loops, presentation interfaces, and update soundness  
Claim boundary: not observer metaphysics, not consciousness, not agency, not selfhood, not value, not moral standing, not Omega validation

## Purpose

Recent outside observer-theory discussion is useful as instrumentation language:

```text
Where does the loop close?
```

Omega's stricter question is:

```text
Does the loop close soundly?
```

That means the observation/update/action loop must not fabricate the information state it uses to justify corridor maintenance.

## Bounded Observer Translation

In Omega terms, a bounded observer is not primitive. It is a presentation/update interface:

```text
boundary;
budget;
compression;
observation channel;
update rule;
action interface;
provenance and soundness obligations.
```

Boundedness forces compression. Compression forces presentation. Presentation requires soundness contracts.

## Closed Loop Is Not Certified Loop

B2.1 gives the guardrail:

```text
sound update:
  evidence never eliminates a true model that could have produced the observed
  successor.

fake update:
  the true model is deleted, the remaining false model certifies a policy, and
  that policy fails in the excluded true world.
```

So:

```text
closed loop != certified loop
```

The fake-update witness is the finite anatomy of phantom loop closure.

## Instrument / Agent Guardrail

Sampling accuracy is not the same as corridor maintenance:

```text
instrument:
  samples or reports.

closed-loop deformer:
  observation changes internal state;
  internal state changes action;
  action changes future observation or corridor position.
```

Even the second category is not yet agency. It is a deformer-profile surface requiring feedback, reflexive maintenance, recovery, and presentation-transport checks before stronger language is warranted.

## Public Compression

Observer-theory asks when the loop closes. Omega asks whether that closure is certified:

```text
an observer/action loop is admissible only if its update rule preserves the live
consequence-bearing distinctions needed for corridor maintenance.
```
