## Current B2 Object

The current B2 stack proves results about the shared-action robust viability
kernel:

```text
RVK(F)
```

for a finite possibilistic ambiguity family. Its semantics are conservative:

```text
one action must be safe and enabled across every declared model;
successors from all declared models are treated as live possibilities;
the finite-prefix converse allows adversarial model choice at each step.
```

This is the right object for:

```text
persistence against switching / stepwise adversarial ambiguity.
```

It is not the right object for every kind of uncertainty.

## Switching Versus Fixed-World

The B2 theorem should not be compressed as:

```text
persistence under uncertainty requires RVK confinement.
```

The correct compression is:

```text
persistence against stepwise adversarial ambiguity requires confinement to the
shared-action robust viability kernel.
```

For unknown-but-fixed worlds, model identity may be learned from observations
or transitions. A policy can sometimes take a safe probing action, identify the
actual model, and then branch safely. Such a state can lie outside switching
`RVK` while still being viable under fixed-world adaptive semantics.

That is not a contradiction. It means the objects differ:

```text
known-model corridor:
  one model is known from the start.

switching robust corridor:
  the model may vary adversarially at each step.

adaptive fixed-world corridor:
  the model is fixed but initially unknown and may be learned.
```

## Conditional-Normativity Reading

The B2 corridor supports only a hypothetical imperative:

```text
IF persistence against the declared switching ambiguity family is required,
THEN actions that leave the certified switching corridor are inadmissible under
that requirement.
```

The antecedent is ledger content. The theorem does not prove that persistence
is good, required, value-bearing, or morally standing.
