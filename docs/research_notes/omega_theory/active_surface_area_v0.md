# Active Surface Area v0

Status: project navigation and branch-control note
Scope: active, frozen, open, proposed, deprecated, and quarantined work surfaces
Claim boundary: map only; not theorem closure, not empirical validation, not Omega validation

## Purpose

The project now has enough concurrent fronts that "what are we working on?"
needs its own tracked artifact. This note records the active surface area so
future work does not accidentally revive deprecated language, overread pilot
results, or leave open branches unowned.

Status labels:

```text
active:
  live surface being extended or directly built on.

running:
  active validation/instrumentation surface with retained outputs.

open:
  conceptually live but blocked on theorem extraction, better adapters, or
  sharper definitions.

proposed:
  plausible branch, not yet committed as a main work stream.

frozen:
  useful checkpoint; do not expand unless a downstream proof needs it.

closed:
  completed narrow question, retained for citation.

deprecated:
  superseded implementation or vocabulary.

quarantined:
  speculative generator only; not allowed in claims without new formal support.
```

## Decision Gates

Before promoting any branch, ask:

```text
1. Is the object derived, supplied, contractual, or empirical?
2. Is there a strictness witness blocking the tempting weaker proxy?
3. Is there a transport/coherence theorem for presentation changes?
4. Is there a retained positive and negative/control case?
5. Does the claim survive the effective-layer map without smuggling agency,
   identity, value, or Omega into a lower layer?
```

If any answer is unclear, keep the branch exploratory or documentation-only.
