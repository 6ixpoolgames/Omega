# Does The Loop Close Soundly? Internal Bridge v0

Status: internal bridge note
Scope: observer theory, NKS-adjacent bounded computation, and Omega's sound-update guardrail
Claim boundary: not consciousness, not agency, not selfhood, not value, not moral standing, not terminal metaphysics, not Omega validation

## Purpose

Observer-theory language is useful as instrumentation:

```text
Where does the loop close?
```

Omega's stricter question is:

```text
Does the loop close soundly?
```

That means the observation/update/action loop must not fabricate the
information state it uses to justify corridor maintenance.

This note is the internal bridge behind the lighter public note:

```text
docs/public/does_the_loop_close_soundly_v0.md
```

## Bounded Observer Translation

In Omega terms, a bounded observer is not primitive. It is a
presentation/update interface:

```text
boundary;
budget;
compression;
observation channel;
update rule;
action interface;
provenance and soundness obligations.
```

Boundedness forces compression. Compression forces presentation. Presentation
requires soundness contracts.

## Closed Loop Is Not Certified Loop

B2.1 gives the guardrail:

```text
sound update:
  evidence never eliminates a true model that could have produced the observed
  successor.

fake update:
  the true model is deleted, the remaining false model certifies a policy, and
  that policy fails in the excluded true world.
```

So:

```text
closed loop != certified loop
```

The fake-update witness is the finite anatomy of phantom loop closure.

## Instrument / Agent Guardrail

Sampling accuracy is not the same as corridor maintenance:

```text
instrument:
  samples or reports.

closed-loop deformer:
  observation changes internal state;
  internal state changes action;
  action changes future observation or corridor position.
```

Even the second category is not yet agency. It is a deformer-profile surface
requiring feedback, reflexive maintenance, recovery, and presentation-transport
checks before stronger language is warranted.

## Current Omega Surfaces

The public note compresses three retained surfaces:

```text
sound update:
  a learner's information state must not eliminate live models without
  certified evidence.

recovery-aware gates:
  an action is rejected when it causes declared nonrecoverable loss under the
  true recovery frame.

reflection:
```

## Public Compression

Observer theory asks when the loop closes. Omega asks whether that closure is
certified:

```text
an observer/action loop is admissible only if its update rule preserves the
live consequence-bearing distinctions needed for corridor maintenance.
```
