# Current Theory Posture v0

Status: consolidation and branch-orientation note
Scope: current Layer A research posture, relation to Gradient Ethics / value preservation under uncertainty, and claim boundaries
Claim boundary: not a theorem, not empirical validation, not value, agency, identity, valuerhood, or Omega validation

## Purpose

This note records the current theoretical branch of the project after the
standard-core compression, recurrent-support, adapter, and stochastic recovery
work.

The short version:

```text
Layer A is currently a continuation-map integrity discipline.
```

July 2026 update:

```text
The active theorem front has moved into the decision/corridor/adaptive-learning
stack. Layer A remains the map-integrity floor, but the live public path now
runs through ODT0 licensing, B2 robust corridors, B2.1 adaptive fixed-world

```

June 25, 2026 reorientation:

```text
Alpha-Omega should be read as a staged effective-theory program, not as a

```

The current layer map is:

```text
Valuer
  forgets to Agent

Agent
  forgets to Continuation

Continuation
  forgets to Alpha
```

Higher-layer structures should leave lower-layer traces, but lower-layer traces
do not canonically determine higher-layer semantics. The detailed map is in
`effective_layers_realization_forgetting_emergence_v0.md`.

It studies when summaries, quotients, presentations, observations, decoders,
policies, supports, and adapters preserve the continuation facts they are used
to reason about.

That is not the whole Alpha-Omega ambition. It is the floor the larger ambition
needs before claims about value-bearing continuation can stop being poetic.

## The Current Branch

The live branch is not:

```text
derive value directly;
detect agents;
define identity;
validate Omega;
turn finite toy worlds into empirical claims.
```

The live branch is:

```text
identify consequence-bearing distinctions;
test whether proposed maps preserve or erase them;
show when summaries fail to determine declared targets;
show when abstractions fabricate or hide continuation facts;
grade recovery under stochastic uncertainty;
separate individual robustness from joint robustness.
```

This is why much of the recent work has focused on:

```text
sound quotients;
presentation invariance;
non-factorization;
exact and approximate recovery;
robust ambiguity sets;
prior-relative recovery;
policy-conditioned hit profiles;
phantom reachability;
hidden loss;
recurrent support integrity;
finite adapter provenance.
```

These are all versions of one question:

```text
Does this representation preserve the consequence-bearing continuation
structure it is being used to reason about?
```

## Why This Is The Right Detour

The larger intuition is that value requires valuers, or at least
value-capable trajectories. If every possible continuation destroys the
conditions under which valuers can arise, persist, interact, revise, or create,
then realized value has been foreclosed.

But valuers, selves, boundaries, and identities are exactly the concepts most
likely to be smuggled in too early. The project therefore starts below them.
It asks which distinctions become consequence-bearing before value language is
introduced, and which maps are allowed to erase those distinctions.

This is the bridge to Gradient Ethics / value preservation under uncertainty:

```text
under uncertainty and irreversibility, preserving the conditions for
value-bearing continuation is a structural safety constraint.
```

The current theorem stack does not prove a full ethical theory. It supports the
weaker claim that some abstractions, policies, and summaries can be formally
rejected because they hide loss, fabricate continuation, or fail to preserve a
declared consequence-bearing target.

The effective-layer reorientation adds one caveat:

```text
the current stack can constrain value-bearing continuation claims, but it does
not choose the valuer, the agency realization, or the value-relevant Phi by
itself.
```

## What Is Supplied

The current lower stack does not derive every ingredient from Alpha.

The old supplied/derived split is useful but too coarse. Use the refined
statuses from the effective-layer map:

```text
primitive;
freely generated;
realization-supplied;
certified;
empirically inferred;
normatively supplied.
```

These are typically supplied by a substrate, adapter, or modeling choice:

```text
fragment/state carrier;
contexts;
outcomes;
comparison relation;
evaluated panel;
transition relation or stochastic kernel;
safety predicate;
target predicate;
observation map;
decoder class;
policy class;
prior;
ambiguity set;
support or carrier candidate;
presentation or summary.
```

That is not a defect by itself. The formal layer proves conditional facts:

```text
given these declared structures, this proxy fails;
given this presentation, this reachability claim is phantom;
given this ambiguity set, this decoder is or is not robust;
given this support, this recurrent carrying survives or fails.
```

The adapter/provenance layer is responsible for explaining why the supplied
structures model the substrate under review.

## What Is Derived

Once the substrate supplies the relevant surface, the current stack derives:

```text
consequence-identifiability and merge separation;
sound quotient / sound presentation checks;
non-factorization witnesses;
class soundness as clique soundness;
support-exact recovery as the threshold-one recovery endpoint;
source-indexed recovery profiles;
deterministic, randomized, robust, and prior-relative recovery checks;
finite-horizon hit profiles under fixed or policy-induced kernels;
phantom and hidden-loss counterexamples;
recurrent support carrying and perturbation strictness;
joint robustness failures under shared ambiguity.
```

The derived layer is intentionally exact and finite at first. Tiny finite
worlds are not the final substrate; they are the audit bench where false
principles can be exposed cheaply.

## What We Should Not Compress Away

Recent work created many names. Some should be compressed in prose, but several
axes remain load-bearing:

```text
unrestricted recovery vs recovery inside a declared decoder class;
deterministic vs randomized decoder access;
single-channel recovery vs robust recovery over an ambiguity set;
worst-case recovery vs prior-relative expected recovery;
marginal recovery vs joint recovery;
fixed kernel hit profiles vs policy-conditioned hit profiles;
support-exact recovery vs approximate threshold recovery;
individual robust policy success vs joint robust policy success.
```

Over-compressing these would hide assumptions the theory is specifically trying
to surface.

## How This Relates To Alpha-Omega

Alpha is the primitive-facing side:

```text
relation;
distinction;
asymmetry;
primitive noncollapse;
primitive exposure to consequence.
```

Omega is the downstream ambition:

```text
the maximal compatible preservation and development of value-bearing
continuation.
```

Layer A sits between them. Its current job is not to announce Omega, but to
build the audit discipline required for any future Omega-like claim:

```text
if a map, metric, policy, boundary, or abstraction cannot preserve declared
consequence-bearing continuation facts, it cannot certify the corridor.
```

The strongest current success condition is therefore staged:

```text
Alpha constrains Continuation;
Continuation constrains Agency;
Agency constrains Valuer-realization;
Valuer-realization constrains Gradient Ethics.
```

If the tower has stable realization and forgetting maps, then value-from-Alpha
is a legitimate long-run target. It is not a direct proof from bare primitive
distinction.

In that sense, proto-teleology is the current milestone. It gives a weak,
constraint-based alignment floor:

```text
a difference matters when erasing it changes what can follow.
```

That is weaker than value, but strong enough to reject unsafe maps.

## Current Implementation Posture

Near-term work should mostly consolidate rather than expand ontology.

The useful next actions are:

```text
keep the theorem spine legible;
keep adapter provenance explicit;
keep stochastic/recovery axes from collapsing into one overloaded concept;
add retained validation summaries when adapter studies mature;
prefer strictness, non-implication, and adversarial witnesses over new names;
document which assumptions are supplied and which facts are derived.
```

Theory expansion should be allowed when it pays for one of these:

```text
it removes a hidden assumption;
it turns a hand-labeled surface into a derived one;
it connects two already-checked layers;
it adds a negative control or strictness witness;
it lets adapter evidence be audited more honestly.
```

## Non-Claims

This posture does not claim:

```text
value detection;
valuer detection;
agency detection;
identity or selfhood detection;
empirical correctness of an adapter;
semantic correctness of a chosen target;
moral status of a threshold;
global randomized optimization;
Omega validation.
```

The current claim is narrower and stronger:

```text
the repo is building a formal and adapter-facing discipline for when
future-facing maps are allowed to be trusted.
```

That is the current branch.
