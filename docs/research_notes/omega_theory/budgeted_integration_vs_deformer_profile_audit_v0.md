# Budgeted Integration vs Deformer Profile Audit v0

Status: detector-coordinate audit note  
Scope: budget-relative integration as a possible observer/interface coordinate  
Claim boundary: not IIT, not consciousness, not agency, not valuerhood, not moral standing, not value, not Omega validation

## Purpose

Budgeted integration is a plausible useful coordinate for bounded observer/interface analysis:

```text
what distinctions can this bounded system integrate within its resource budget?
```

Omega should mine that as instrumentation, not metaphysics.

## Safe Reading

Budget-relative integration may help characterize:

```text
bounded compression;
interface richness;
observation/update capacity;
closed-loop deformer profiles;
which distinctions are available to a policy in time.
```

It does not by itself define:

```text
consciousness;
valuerhood;
standing;
agency;
utility;
Omega.
```

## Audit Question

The useful question is whether budgeted integration separates cases that existing profile coordinates do not:

```text
recurrence;
control reach;
feedback advantage;
reflexive maintenance;
own-maintenance score;
joint-continuation effect;
adaptive-kernel membership;
correction-register recoverability.
```

If it separates none of these, it is likely a proxy shadow. If it separates some retained witness family, it may deserve a detector-coordinate slot.

## Guardrail

Do not infer:

```text
high integration -> agency
high integration -> value
high integration -> moral standing
high integration -> presentation soundness
```

The last point is load-bearing: an integrated representation can still hide loss or fabricate recoverability.

## Candidate Witness

A finite audit should compare:

```text
same task success;
same or similar budgeted-integration score;
different adaptive-kernel membership or correction-register recoverability.
```

That would tell us whether budgeted integration is a useful independent detector or just another surface-level summary.

## Next Pressure

Keep this as an audit target until a concrete finite witness exists. Do not promote it into the theorem spine before it earns a strictness or separation role.
