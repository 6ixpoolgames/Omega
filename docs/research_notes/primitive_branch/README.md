# Primitive Branch Notes

This folder contains the lower-layer theory notes that clarify what must be true before valuerhood is definable.

The canonical primitive stack is now:

```text
distinction:
  differences exist

asymmetry:
  different paths produce different consequences

relation:
  causal continuity links differences across transformation

identity:
  organized causal continuity through change
```

## Reading order

1. [`relation_as_historical_binding.md`](relation_as_historical_binding.md)

   Canonical title: **Relation as Causal Continuity**.

   The filename is retained for continuity with earlier drafts, but the current definition of relation is causal continuity, not historical conditioning. Historical conditioning belongs to the identity/trajectory layer.

2. [`omega_meets_fep.md`](omega_meets_fep.md)

   Defines the handoff from the primitive floor to the FEP / self-maintenance floor.

3. [`valuerhood_as_recoverable_historical_identity.md`](valuerhood_as_recoverable_historical_identity.md)

   Defines valuerhood as a bounded historical identity whose continuations asymmetrically affect recoverable continuability.

## Anti-drift reminders

- Relation is not primarily inter-agent relation, graph adjacency, social coupling, or historical conditioning.
- Identity is not material sameness or exact state recurrence.
- Valuerhood does not require consciousness, preference, utility, or human-like agency.
- Minimal worlds and cellular automata are floor-calibration tools, not Omega validation.
