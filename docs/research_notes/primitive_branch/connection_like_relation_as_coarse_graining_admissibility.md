# Connection-Like Relation as Coarse-Graining Admissibility

Omega's current main-track object can be written schematically as:

```text
I_T^C(s) = H(F_T(s) / C)
```

where:

```text
F_T(s) = viable future trajectories from state s to horizon T
C      = coarse-graining over those trajectories
H      = entropy over distinguishable viable macro-trajectory classes
```

The object depends critically on the choice of `C`. If `C` is arbitrary, the
object becomes too permissive: random labels, raw trajectory richness, local
memory, commutative averaging, lock-in, and component-only channels can all
create apparent distinguishability without preserving the structure Omega is
trying to identify.

The immediate open problem is therefore:

```text
What makes a coarse-graining admissible?
```

The primitive branch suggests a candidate answer:

```text
A coarse-graining C is admissible only if it preserves connection-like
transport of distinction-history through viable futures.
```

## Primitive Bridge

The primitive branch currently uses:

```text
distinction = difference
asymmetry   = consequence
relation    = dependence
```

Recent DA probes showed that cheap forms of these primitives are not enough:

- cheap distinction: random difference or self-only persistence;
- cheap asymmetry: bias, irreversibility, or non-commutativity without
  meaningful transported consequence;
- cheap relation: coupling, edge memory, local storage, or momentary
  dependence.

The emerging refinement is:

```text
relation = identity-carrying transport of distinction-history across contexts
```

This gives relation a mathematical job. It is not merely an edge, correlation,
memory store, or interaction. It is a rule for how a distinction in one context
is carried, transformed, degraded, branched, or closed through another context.

## Admissibility Criterion

A coarse-graining `C` should not merely group futures that look similar at
endpoints or have high entropy. It should preserve the macro-structure of
viable transport.

A candidate criterion:

```text
C is connection-admissible over F_T(s) if the macro-classes induced by C
support identity-carrying transport along viable trajectory segments.
```

Operationally:

1. True macro-path composition predicts transported identity better than
   shuffled or random paths.
2. Removing or shuffling relation destroys the transport signal.
3. Local memory alone cannot preserve the relevant macro-identity.
4. Random relation, generic coupling, and commutative/global maps cannot fake
   the signal.
5. Lock-in or collapse cannot count as successful transport.
6. Multiple future-distinct transported alternatives remain viable.

This connects the main object to the primitive branch:

```text
I_T^C(s):
  requires admissible C

DAR primitive branch:
  searches for the structure that makes C admissible

DAX-R:
  tests whether connection-like relation is a valid primitive criterion for C
```

## Guardrail

DAX-R is not an Omega validation probe. Passing DAX-R would establish only a
constructed substrate where connection-like relation is valid enough to support
later viable-slack or adjudication tests.

DAX-R does not show that connection-like relation emerges spontaneously from
simpler DAR dynamics. That downstream emergence question remains separate.

The immediate experimental task is narrower:

```text
Make relation real.
```

That means making relation connection-like enough that arbitrary
coarse-grainings, local memory, random relation, commutative averaging, and
lock-in cannot impersonate it.
