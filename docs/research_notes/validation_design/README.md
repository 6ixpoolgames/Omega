# Validation Design Notes

This folder contains current validation designs for the Omega project.

Omega should be introduced to new readers as a structural theory of
value-bearing futures. VAL0-G is the current minimal executable precursor to
that larger theory: it asks whether recoverable-continuation geometry can be
detected in neutral constructor-style task space before making any claim about
full Omega.

The current public-facing validation target is **VAL0-G**:

```text
neutral-grammar geometry atlas in constructor-style task algebras
```

VAL0-G does not attempt to validate full Omega, valuerhood, ethics, or
multifield compatibility. It tests a narrower precursor:

```text
recoverable continuation geometry under asymmetric transformation
```

## Current Primary Question

```text
Do neutral constructor-like task spaces generate measurable geometry classes
where asymmetric continuation dynamics filter trajectories into
self-terminating, brittle, noisy, lock-in, and recoverable regimes?
```

## Implementation Stance

- CPU-first.
- Neutral generator primitives before outcome labels.
- Survival curves and descendant mass before policy victory.
- Post-hoc geometry classes only; do not label worlds as recoverable/brittle in
  the generator.
- Use VAL0-CT anchors and dense controls as guardrails, not as the current
  object.
- Defer embodied agents, multifield coupling, re-entry redesign, lineage, and
  GPU acceleration until the neutral grammar smoke is clean.
