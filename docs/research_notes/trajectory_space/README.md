## Relationship To Current Work

The trajectory-space branch asks whether viable propagation can be detected more
directly from viable trajectory measures, hazard structure, recoverability,
trajectory concentration, and temporal dependence before choosing a macro-fiber
quotient.

The current operational witness remains quotient-relative:

```text

```
