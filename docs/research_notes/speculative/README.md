# Speculative Research Notes

Status: quarantined hypothesis space

This folder is for high-level theory exploration that has not been admitted to
the claims ledger.

Speculative notes may propose metaphors, correspondences, or possible theorem
targets. They should not be read as validated project claims unless a separate
checked Lean theorem, executable validation artifact, or reviewed result note
says so.

Useful rule:

```text
metaphor can generate hypotheses;
only proof, validation, or explicit evidence can promote claims.
```
