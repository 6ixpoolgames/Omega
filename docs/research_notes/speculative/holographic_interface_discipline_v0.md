# Holographic Interface Discipline v0

Status: speculative theory note

This note records a disciplined way to use the holography / event-horizon
intuition without smuggling primitive identity, deformer objects, singularities,
agency, or value into the theory.

## Core Principle

No-self and boundary nonprivileging do not forbid proxy identity from the
outside. They forbid treating proxy identity as final, primitive, or
self-evidenced.

The admissible replacement is:

```text
proxy identity relative to a declared interface profile
```

An outside observer may treat two interiors as the same proxy object when their
certified interface profiles agree under the declared probe panel, horizon,
presentation, and target.

The metadata is not optional.

## Interface Profile

The safe evidence surface is not the interior object. It is the interface
profile:

```text
inputs / perturbations entering the region
outputs / observations leaving the region
declared distinctions recoverable at the interface
reachability / viability / loss facts visible through the interface
capacity limits of the interface
```

The project may use a hidden region as explanatory shorthand only when its
claimed effects are expressed through such an interface profile.

## Deformation Without Deformer Identity

Do not define:

```text
Deformer : Type
```

as primitive.

Define instead:

```text
DeformationSignature P :=
  some declared interface/profile/target changes under P
```

Then "deformer" is shorthand for a repeatable source of profile changes, not an
object whose identity is assumed.

## Event-Horizon / Channeling Intuition

The useful intuition is:

```text
diffuse inputs enter a high-gain transformation region;
the region scrambles, compresses, selects, or reorganizes them;
outputs emerge through a sharper interface profile.
```

That sharpening can be integrative or destructive.

Integrative sharpening:

```text
declared input distinctions remain recoverable;
joint viability is preserved;
compatible supports are composed rather than digested.
```

Destructive sharpening:

```text
important distinctions are unrecoverable;
only a proxy survives;
joint viability contracts;
plural supports become optimizer-mediated filaments.
```

So "more structured output" is not automatically good. A prison, monopoly,
total institution, or proxy optimizer can be highly structured.

The alignment-relevant question is:

```text
does the sharpening preserve compatible value-bearing continuation?
```

## Formal Shadow

The immediate finite theorem target is not a deformer theorem. It is a
non-factorization theorem:

```text
same sharp interface summary
different declared input-distinction recovery
```

Lean location:

```text
formal/lean/OmegaProper/BaselineWitnesses/InterfaceSharpnessDeclaredRecovery.lean
```

The theorem says that a coarse structured-output summary does not determine
whether the interface preserved the declared input distinction.

## Research Uses

This discipline supports several future branches:

```text
no-hair:
  different interiors with the same certified interface profile

scrambling:
  input distinctions are not immediately recoverable at the interface

delayed recovery:
  a later output panel recovers a distinction not visible earlier

capacity:
  the interface cannot faithfully carry all declared distinctions

horizon:
  exit/recovery facts vanish after crossing a boundary in continuation space

optimization pressure:
  an external transformation changes support, recovery, reachability, or
  viability profiles
```

All of these should remain profile-level claims until formalized.

## Claim Boundary

This note does not claim:

```text
agents are black holes;
deformers are real objects;
singularities have been defined;
proxy identity is metaphysically final;
value has been detected;
agency has been detected;
Omega has been validated.
```

The only endorsed discipline is:

```text
use interface-stable proxy identities when useful,
but keep them declared, target-relative, and audited for recovery/loss.
```
