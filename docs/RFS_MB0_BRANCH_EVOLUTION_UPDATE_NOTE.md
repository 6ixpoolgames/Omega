# RFS-MB0 Branch Evolution Note: From Neutral Relation Substrate to Guided Support/Distribution Atlas

Status: update note for onboarding and branch documentation  
Scope: current RFS-MB0 empirical branch, from substrate reset through the 10h medium-breadth atlas plan

## 0. Purpose

This note documents the evolution of the current empirical branch: what changed, why it changed, what we learned, and how our interpretation standards shifted.

The short version:

```text
We started with a future-landscape detector and substrate that were too semantically loaded and too easy to overcall.

We reset toward a neutral action-generated relation substrate.

Then we spent several audit cycles separating:
  real candidate evidence
  detector artifacts
  probe artifacts
  support/deformation effects
  mechanism dependence
  destructive ablation effects
  roughness sensitivity
  path metric fakeouts

The current active lane is now:
  support/distribution deformation taxonomy and regime mapping

Path/process metrics are parked until probe resolution and matched-control issues improve.
```

The current branch is not claiming Omega, agency, identity, value, viability, or scientific-gate passage.

The current empirical object is narrower:

```text
future-landscape support/distribution deformation generated by neutral relation/asymmetry/constraint substrates
```

## 1. Initial concern: detector overcall and semantic substrate drift

The earliest branch state had two problems.

First, the detector could overcall structure from local/window features. It was too easy for degree controls or simple local features to be interpreted as structured propagation.

Second, the substrate risked smuggling in semantics. Even when labels were cleaned up, relation families still carried hand-designed roles, such as expanding, contracting, cyclic, or structured behavior.

This violated the intended methodology:

```text
Start from the primitive triad:
  distinction
  relation/transformation
  asymmetry

Then observe what future-landscape deformations emerge downstream.
```

The branch reset away from hand-named relation classes toward a neutral relation generator.

## 2. First major correction: detector should not promote local hits directly

Early smoke results showed local hits could appear in controls. The detector needed to distinguish:

```text
local/window candidate behavior
```

from:

```text
aggregate family/probe-family evidence
```

The correction was:

```text
keep local hits visible
but prevent local hits from promoting aggregate claims unless they survive stricter control-relative standards
```

This made the result stricter and less crank-adjacent.

Important interpretation change:

```text
A local candidate is not a pass.
A local candidate is an object for audit.
```

## 3. Horizon audit: longer horizons did not rescue the old substrate

A longer horizon run was added to check whether previous failures were caused by ending too early.

That audit showed that the old substrate remained problematic even when horizons were extended. The issue was not only horizon cutoff. The old substrate had deeper design problems:

```text
fast saturation
poorly controlled endpoint structure
hand-designed relation roles
semantic drift
```

This justified moving fully to the neutral action-generated relation atlas.

## 4. Neutral action-generated relation generator

The branch then introduced an action-generated relation substrate.

A state is a finite coordinate tuple. Candidate successors are generated by local updates. Edges are selected by a neutral score:

```text
change term
+ constraint violation term
+ constraint change penalty
+ asymmetry term
+ roughness term
```

Then the lowest-scoring candidate successors become the outgoing relation edges.

This gave the branch a much cleaner substrate:

```text
distinction:
  finite coordinate states

relation/transformation:
  top-k local transition relation

asymmetry:
  directed score bias

constraint:
  local compatibility geometry shaping reachable futures
```

The generator initially looked plausible. It produced middle-regime environments and avoided direct semantic labels.

## 5. Cost discussion: defer cost as primitive, keep as diagnostic

During the branch, we discussed cost and path length.

The concern was that adding an explicit cost economy too early would risk smuggling in resource-game semantics. However, cost-like diagnostics remain important because they help identify fake persistence, stasis, and terminal attractor artifacts.

The working stance became:

```text
Do not implement cost as a primitive state variable yet.

Keep cost-like diagnostics in the background:
  path length
  probability steering needed to reproduce structure from null
  entropy / divergence from random generation
  maintenance-like burden
```

This led to the idea that “work” could be approximated as:

```text
how much probability steering is required to produce a future-landscape structure from a null process
```

That remains conceptually useful, but it is not yet implemented as a substrate primitive.

## 6. Constraint and asymmetry: nulls versus ablations

A major interpretive correction happened around nulls.

Initially, many controls were treated as if candidates should “survive” them.

That was wrong for several controls.

Constraint and asymmetry are not incidental. They are part of the structure-generating machinery. Therefore:

```text
constraint_shuffled
asymmetry_shuffled
degree/out-degree rewires
```

should not all be treated as ordinary must-survive nulls.

We separated controls into categories.

### 6.1 Triviality controls

These test whether an effect is explainable by low-level endpoint/probe facts:

```text
frontier_size_only
probe_marginal_only
frontier_size_plus_probe_marginal
```

Candidates should generally clear these for stronger claims.

### 6.2 Support-level controls

These test whether the effect is mostly about which futures/signatures become reachable:

```text
signature_support_matched
horizon_local_frontier_matched
window_local_frontier_matched
```

Failing these does not mean immediate rejection. It may mean:

```text
support_deformation_candidate
```

Support deformation is a legitimate lower-level future-landscape phenotype.

### 6.3 Mechanistic ablations

These disrupt the mechanisms generating the relation landscape:

```text
constraint_shuffled
asymmetry_shuffled
```

Meaningful candidates may die under these. That death can indicate mechanism dependence, not falsification.

### 6.4 Strong graph/relation ablations

These disrupt relation geometry more broadly:

```text
out_degree_preserving_random
degree_preserving_rewire
```

We later noted that the current `degree_preserving_rewire` name is too strong. It is closer to an out-degree-preserving random target rewire than a true directed in/out degree-sequence preserving edge swap.

These are useful for detecting generic branching artifacts, but they should not be interpreted as a requirement that relation-specific candidates survive the destruction of relation geometry.

### 6.5 Robustness perturbations

These should be graded:

```text
multiple starts
roughness strength/reseed sweeps
small perturbations
presentation changes
```

These are better robustness instruments than destructive ablations.

## 7. Roughness: from artifact label to sensitivity profile

Roughness was initially concerning because roughness-resampled controls killed many candidate labels.

But later score-term decomposition showed that roughness was not dominating edge selection. The generator was strongly constraint-dominated.

This revealed that the previous label:

```text
roughness_brittle_artifact
```

was too blunt.

The interpretation was refined into:

```text
roughness_resample_sensitive
roughness_edge_brittle
confirmed_roughness_artifact
symmetry_breaking_stable
noise_tolerant
noise_sensitive_smooth
```

The key correction:

```text
Failing a roughness-resampled control does not automatically mean the candidate was generated by roughness.

It may mean phenotype-level sensitivity, frontier amplification, or null-rank instability.
```

The repaired run found that confirmed roughness artifacts were rare, while many candidates were better described as:

```text
constraint-dominated
roughness-sensitive
edge-stable
noise-tolerant
```

This materially improved confidence in keeping the relation generator.

## 8. Multiple starts became mandatory

Another major correction was around starts.

A “start” is the initial state from which a future landscape is computed.

The prior use of `start_samples = 1` made it impossible to tell whether a candidate was:

```text
environment-level
basin-local
start-local
a lucky frontier accident
```

The branch made multiple starts mandatory:

```text
start_samples = 3
start_samples = 8
```

and sometimes optionally:

```text
start_samples = 16
```

Candidate phenotypes are now typed by start coverage:

```text
start_local
basin_local
environment_level
start_fragile
start_diverse
```

This became the first non-destructive sanity layer.

## 9. Candidate phenotype audit

The branch then moved from pass/fail candidate logic to phenotype vectors.

Each candidate needed to be described by:

```text
start coverage
probe family
support result
distribution result
roughness response
constraint/asymmetry dependence
matched-control behavior
probe limitation
fakeout class
mechanism tags
```

This was a major conceptual shift.

Instead of asking:

```text
Did the candidate survive all nulls?
```

we asked:

```text
What kind of deformation or fakeout is this?
What does it depend on?
Does it recur at the phenotype level?
```

This helped avoid overfiltering and preserved potentially useful near-miss behavior.

## 10. Path/process branch and why it was parked

After the relation generator looked healthy enough, we explored whether candidate phenotypes showed path/process structure.

Codex flagged that path metrics could be too permissive. We agreed.

A finite constrained graph almost always produces:

```text
repeated bigrams
repeated trigrams
entropy reduction
forbidden words
compression-like structure
```

So raw path metrics were not evidence.

A path metric calibration smoke was run with:

```text
promotion disabled
matched controls mandatory
probe collision diagnostics
fakeout-first reporting
```

The result showed that current path probes were too collision-prone. Pairwise projection probes collapsed the finite state space into a tiny signature alphabet, making recurrence cheap.

A probe-resolution calibration was then run. Higher-resolution probes helped somewhat, but matched controls still often showed similar metrics, and strict-state probes were identity-like controls rather than evidence probes.

The branch decision was:

```text
B. Downgrade path-process for now and focus on support/distribution deformation taxonomy.
```

Path metrics remain available for later, but they no longer drive the current branch.

## 11. Indirect detection and the identity problem

A recurring motivation for this branch is that direct agent or identity detection is premature.

The theory side has not earned a clean operational definition of:

```text
agent
identity
valuer
self
persistent object
```

inside the primitive substrate. Hand-defining those classes would recreate the same problem the substrate reset was meant to avoid: smuggling semantic categories into the implementation and then “discovering” them later.

The empirical move is therefore indirect.

Instead of asking:

```text
Which object is the agent?
Which identity persists?
Which state is value-bearing?
```

we ask:

```text
Does the future landscape show deformation patterns compatible with something organizing reachable futures?
```

This is the “dark matter” analogy for the empirical arm. We may not directly label the value-bearing or agent-like object, but we can look for its shadow:

```text
changes in reachable support
changes in endpoint distributions
stabilized or excluded future regions
recurring deformation phenotypes
fakeouts that resemble future-interest but collapse under controls
```

This reframes the empirical target from object detection to landscape deformation detection.

## 12. Support/distribution deformation became the active empirical lane

The current empirical object was narrowed to:

```text
support/distribution deformation in future landscapes
```

Definitions:

```text
support deformation:
  which signatures/futures become reachable or unreachable

distribution deformation:
  how mass/counts are distributed over reachable signatures

mixed support/distribution deformation:
  both support and distribution differ from controls
```

This is a lower-level but cleaner target than path-process structure.

It aligns with the dark-matter analogy:

```text
We may not define the value-bearing object directly.

We observe how it deforms the landscape of possible futures.
```

At this stage, the “shadow” we can more reliably instrument is support/distribution deformation.

## 13. Support/distribution taxonomy smoke

A support/distribution taxonomy smoke was run.

It produced:

```text
matched controls
start recurrence
probe diagnostics
mechanism tags
fakeout classes
a preliminary regime map
```

The result was mostly workflow validation and control typing, not strong candidate evidence.

Most candidate rows were matched-control equivalent, but a small residue remained:

```text
mixed_support_distribution_candidate
support_deformation_candidate
```

The key interpretation:

```text
Support/distribution taxonomy is operational.

Candidate evidence is weak but nonzero.

Matched-control equivalence still dominates.

The next question is whether candidate residues and fakeouts are stable, transitional, or artifacts.
```

## 14. Rarity and the abiogenesis analogy

We then explicitly considered rarity.

If the object of interest is rare, we should not expect it to be common in small samples.

The analogy was abiogenesis:

```text
rare does not mean impossible
rare means broad regime search may be necessary
```

But we also noted that breadth only helps after detectors are good enough not to generate fake positives.

Therefore, the correct next move was not blind scaling.

The correct sequence became:

```text
1. harden the deformation detector
2. sweep locally around candidate and fakeout anchors
3. learn transition geometry
4. then run a guided medium-breadth atlas
```

## 15. Deformation detector upgrade and local sweeps

The detector was upgraded from simple smoke thresholds toward:

```text
rank/effect-size scoring
multiple matched-control bundles
margin sensitivity
support-vs-distribution separation
recurrence scoring
explicit fakeout penalties
```

Margin sensitivity was tested across:

```text
0.00
0.01
0.02
0.05
0.10
```

The local sweep then sampled around both candidate residues and fakeout anchors.

This was important because fakeouts may hide near-miss regimes.

The sweep found:

```text
candidate_stable_region
fakeout_to_candidate_transition
candidate_to_fakeout_transition
saturation_boundary
probe_resolution_boundary
```

This was the first strong evidence that there is local transition geometry worth mapping.

Important interpretation:

```text
This does not validate Omega.

It does justify a guided medium-breadth atlas.
```

## 16. Why fakeouts are now part of the object of study

We stopped treating fakeouts as mere failures.

A fakeout can be:

```text
stable artifact basin
near-miss
probe-resolution boundary
support ceiling boundary
matched-control boundary
saturation boundary
candidate precursor
```

This is scientifically useful.

The branch now treats fakeouts as part of the deformation taxonomy.

The question is:

```text
What looks like it cares, but does not actually sustain future-oriented deformation?

What is one parameter move away from a cleaner candidate?

What is a stable artifact?
```

This helps map the empirical phase space.

## 17. Current 10-hour medium-breadth atlas plan

After the local sweep found candidate-stable and fakeout-to-candidate transition regions, the branch moved to a guided medium-breadth atlas.

The 10-hour window should not be spent on blind scaling.

It should be spent on:

```text
breadth across parameter neighborhoods
fresh seeds
matched-control bundles
start recurrence
probe-family recurrence
margin sensitivity
limited n=6 transfer checks
```

The planned stages are:

```text
Stage A: integrity/preflight and anchor-band extraction
Stage B: guided n=5 medium-breadth atlas
Stage C: fresh-seed confirmation on promising bands
Stage D: matched-control bundle expansion and margin audit
Stage E: limited n=6 transfer check
Stage F: final synthesis/regime map
```

If runtime is cheaper than expected, expand in this order:

```text
1. fresh seeds per promising parameter band
2. matched controls per candidate
3. more parameter sets around fakeout-to-candidate bands
4. n=6 transfer checks
5. start_samples=16 for promising bands
```

Do not spend the budget on:

```text
path metrics
n=7/n=8
new substrate machinery
agent/value/identity labels
```

A guided medium-breadth atlas is justified.

## 19. Current working hypothesis

The current working hypothesis is not:

```text
We have found Omega.
```

It is:

```text
Neutral action-generated relation systems may produce rare, regime-dependent support/distribution deformation phenotypes.

These phenotypes may be concentrated near constraint/asymmetry/branching transition bands.

Some fakeouts may represent boundaries or near-misses rather than dead artifacts.

A guided atlas can map these regimes more efficiently than blind scaling.
```

## 20. Current methodological principles

The branch is now guided by four principles.

### 20.1 Neutrality

Stay downstream of the primitive triad. Avoid hand-labeled semantics.

### 20.2 Phenotyping over pass/fail

Candidates and fakeouts should be classified by behavior and dependencies, not simply accepted or discarded.

### 20.3 Matched controls before promotion

Matched controls, margin sensitivity, and recurrence must come before stronger claims.

### 20.4 Breadth after detector hygiene

Breadth is likely necessary, but only after detector overcall and fakeout modes are controlled.

Expected useful outcomes include:

The next run still should not claim Omega, agency, identity, value, viability, path-process detection, or scientific-gate passage.

## 22. Bottom line

The current branch has evolved from:

```text
trying to detect structured propagation directly
```

to:

```text
building a neutral observational science of future-landscape deformation
```

The active empirical target is now:

```text
support/distribution deformation regimes in action-generated relation systems
```

This is narrower, cleaner, and more defensible.

If the guided atlas finds stable deformation bands, the next step is broader regime mapping and a theory note connecting support deformation to the future-landscape shadow concept.

If the guided atlas collapses into fakeouts or matched-control equivalence, the next step is a measurement-limits note and possible reassessment of detector or generator design.
