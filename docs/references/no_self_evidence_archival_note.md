## Why It Matters To This Project

The working lesson taken from the paper is not that boundaries are useless. It is that boundaries and selves should not be treated as directly evidenced primitive entities.

That lesson shaped several project choices:

- Do not define value by first assuming a fixed self or fixed agent boundary.
- Treat boundaries, quotients, and presentations as tools that need soundness conditions.
- Ask whether a presentation erases consequence-bearing distinctions.
- Detect structure through effects on continuation, reachability, viability, and loss, rather than by assuming identity-bearing objects.
- Keep valuerhood and agency downstream of recoverable, consequence-bearing structure.

This influence is especially visible in the sound quotient, presentation-invariance, phantom-reachability, hidden-loss, and loss-aware presentation contract layers.

## Project Interpretation

The repo's current stance is:

```text
No object, self, boundary, or valuer is assumed as primitive.
Presentations are admissible only when they preserve the relevant consequence structure.
Value-bearing futures must eventually be described without depending on an unevidenced fixed boundary.
```

That is a project interpretation inspired by the external paper. It is not a summary endorsed by the paper's authors.
