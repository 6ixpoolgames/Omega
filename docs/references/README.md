# References And External Influences

This directory is for archival notes, bibliographic pointers, and redistribution-safe reference material that influenced the project.

External papers stored or discussed here are not project authorship claims. When a source is not ours, the note should say so clearly and should include citation, license, and redistribution status whenever known.

If a paper cannot be redistributed safely, add an archival note instead of copying the paper into the repo.
