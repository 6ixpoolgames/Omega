# Public Results Index

This index is for outside readers who want to understand the current empirical state of the Omega / Reachable Futures repository without reading every historical artifact.

The repository contains many exploratory runs. The current active branch is a
clean **Future Field Atlas** rebuild over the RFS-MB0 horizon-transport lessons:
raw reachable-frontier topology first, response labels last. Older VAL0/VAL1/RFS0
results remain useful for provenance and failure analysis, but they are not the
current validation center.

## Claim boundary

Current results do **not** claim:

```text
Omega validation
agent detection
valuer detection
identity detection
life detection
self-replication detection
candidate promotion
holdout readiness
graph-channel causality
```

The current claim is modest:

> Directional horizon-transport instrumentation can measure matched-control-separated response profiles in neutral finite transition substrates. Transition-energy substrate laws express different response regimes. Preservation asymmetry is currently the strongest non-template substrate hook for aligned amplification, with low-beta sensitivity now mapped below beta `0.25`; the latest MaxEnt/top-m audits indicate that the current preservation response is narrow to hard top-m selection geometry rather than recovered by the tested stochastic relaxations. The hard-top-m mechanism branch now points toward a fixed low-rank successor-boundary pattern: response appears when the retained selected-edge set is the low-energy rank prefix, not under generic lower out-degree, random deletion, or expansion. The current implementation work is now rebuilding the instrument as a Future Field Atlas so raw topology, rank-boundary anatomy, and transport matrices are emitted before any response labels. Conditions are represented by state-space, transition-law, selection-operator, observable, and frontier-scan specs; formal spec manifests, condition-identity manifests, completeness summaries, and reconstruction audits are now part of the smoke output. Historical treatment names are documentation-only translation aids.

## Current live branch

### Horizon transport

Horizon transport asks what earlier reachable-future structures become at later horizons:

```text
T_{H_a -> H_b}
```

It is a directional matrix family, not a static co-occurrence object.

The H128 response-surface run completed `11520 / 11520` jobs with `0` errors, matched-marginal detector-null separation, `8 / 8` response fixtures passing, and no terminal saturation flags. It emitted only:

```text
transport_stable
transport_amplified_aligned
```

This made horizon transport the live instrument, but it did not validate Omega.

### Transition-energy substrates

The current substrate program uses explicit transition energy:

```text
E(s,t)
```

where `E(s,t)` is an edge-selection score, not utility, reward, fitness, value, moral cost, thermodynamic energy, or Omega.

The minimal ladder is:

```text
E0 locality only:
  E(s,t) = d(s,t) + roughness

E1 directional asymmetry:
  E(s,t) = d(s,t) + alpha * (A(t)-A(s)) + roughness

E2 preservation asymmetry:
  E(s,t) = d(s,t) + beta * |I(t)-I(s)| + roughness

E3 combined asymmetry:
  E(s,t) = d(s,t) + alpha * (A(t)-A(s)) + beta * |I(t)-I(s)| + roughness
```

Current read:

```text
locality-only:
  baseline; no aligned amplification

directional asymmetry:
  rerouting / differentiated response

preservation asymmetry:
  aligned amplification; current loadbearing family

combined asymmetry:
  clean and rerouting-bearing, not yet synergistic in tested grid
```

## How to evaluate future results

For any future result note, check:

```text
Did all jobs complete?
Were there errors?
Did matched marginal detector-null gates pass?
Did the fixture contract pass?
Were response rows interpretable, or measurement-limited?
Are baseline-missing rows separated from response classes?
Does the result alter the instrument, the substrate family, or the broader theory?
Does the note explicitly block Omega/agency/value/candidate claims?
```

A useful result can still be strictly below validation.
