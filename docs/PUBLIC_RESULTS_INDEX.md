## Claim boundary

Current results do **not** claim:

```text
Omega validation
agent detection
valuer detection
identity detection
life detection
self-replication detection
candidate promotion
holdout readiness
graph-channel causality
```

The current claim is modest:

> Future Field Atlas can measure reconstructible finite future-field topology
> under lawful transition substrates. Current rank-order-boundary coupled
> results show a marginal-preserving joint-restriction class under
> `symbol_histogram_distance` with high-yield representatives `pair005`,
> `pair012`, `pair014`, and `pair026`. The two tested alternate observables did
> not reproduce the high-yield signature. The first formal-interface distinction
> panel now maps this representative/control set into declared finite
> distinction-measure artifacts with 40 / 40 cells available and 0 missing or
> blocked cells. The formal adapter conformance package now compiles that panel
> into contexts, unfoldings, distinction fibers, preorders, transport witnesses,
> closed transports, law checks, and theorem-transfer status for formal-arm
> consumption. Historical treatment names are documentation-only translation aids.

### Horizon transport lineage

Horizon transport asks what earlier reachable-future structures become at later horizons:

```text
T_{H_a -> H_b}
```

It is a directional matrix family, not a static co-occurrence object.

The H128 response-surface run completed `11520 / 11520` jobs with `0` errors, matched-marginal detector-null separation, `8 / 8` response fixtures passing, and no terminal saturation flags. It emitted only:

```text
transport_stable
transport_amplified_aligned
```

This made horizon transport the predecessor instrument to Future Field Atlas,
but it did not validate Omega.

### Transition-energy substrate lineage

The current substrate program uses explicit transition energy:

```text
E(s,t)
```

where `E(s,t)` is an edge-selection score, not utility, reward, fitness, value, moral cost, thermodynamic energy, or Omega.

The minimal ladder is:

```text
E0 locality only:
  E(s,t) = d(s,t) + roughness

E1 directional asymmetry:
  E(s,t) = d(s,t) + alpha * (A(t)-A(s)) + roughness

E2 preservation asymmetry:
  E(s,t) = d(s,t) + beta * |I(t)-I(s)| + roughness

E3 combined asymmetry:
  E(s,t) = d(s,t) + alpha * (A(t)-A(s)) + beta * |I(t)-I(s)| + roughness
```

Current read:

```text
locality-only:
  baseline; no aligned amplification

directional asymmetry:
  rerouting / differentiated response

preservation asymmetry:
  aligned amplification; current loadbearing family

combined asymmetry:
  clean and rerouting-bearing, not yet synergistic in tested grid
```

## How to evaluate future results

For any future result note, check:

```text
Did all jobs complete?
Were there errors?
Did matched marginal detector-null gates pass?
Did the fixture contract pass?
Were response rows interpretable, or measurement-limited?
Are baseline-missing rows separated from response classes?
Does the result alter the instrument, the substrate family, or the broader theory?
Does the note explicitly block Omega/agency/value/candidate claims?
```

A useful result can still be strictly below validation.
