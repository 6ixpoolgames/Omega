# Omega As Compatible Valuer-Trajectory Space v0

Status: reorientation note / roadmap target

Scope: public-facing target statement for Omega after the Alpha migration and
registry-first empirical repair

Claim boundary: this note is not an Omega validation result. It describes the
target object and the evidence discipline needed before stronger claims.

## Compact Statement

Omega is not the preservation of arbitrary distinctions.

The current target is:

```text
Omega is the maximal admissible compatibility structure of future trajectories
in which robust valuer-like process-bundles can arise, persist, interact,
self-correct, branch, and continue to generate meaningful future capacity.
```

Equivalently:

```text
Omega = compatible valuer-bearing futures under uncertainty and irreversibility
```

This target remains aspirational. The repository currently contains formal
scaffolds and finite presentation instruments, not a proof that the target is
physically or ethically realized.

## Stack Order

The corrected conceptual order is:

```text
thermodynamic feasibility
-> localized observer / valuer possibility
-> value preservation under uncertainty
-> action-relevant dynamics
-> viable propagation through quotients
-> Alpha primitive floor
-> derived process-bundles and trajectories
-> jointly compatible valuer-bearing futures
```

The active formal stack should be read as:

```text
Alpha:
  relation, distinction, asymmetry

Dynamics:
  trajectories, transition kernels, actions, perturbations, uncertainty

Process-bundles:
  recoverable temporally extended units with pragmatic, non-ontological
  boundaries

Agents:
  process-bundles with action channels that shape future trajectories

Valuers:
  robust agents for whom futures can matter because their dynamics encode,
  maintain, and act on valuation-relevant distinctions across time

Omega:
  the maximal admissible compatibility structure of futures containing robust
  valuer-trajectories
```

## Why FFA Is Demoted

Future Field Atlas v0 remains useful, but it should be classified as:

```text
preformal reachable-frontier morphology instrument
```

It measures finite frontier topology, selection-operator geometry,
product-vs-coupled baselines, marginal retention, and joint restriction. These
are useful low-level facts. They are not yet evidence of valuerhood.

The right way to retain FFA is:

```text
FFA v0:
  morphology and finite-dynamics stress testing

trajectory atlas:
  future instrument whose primary unit is a process-bundle or trajectory family
```

FFA features can become subordinate diagnostics inside a trajectory-level
instrument, but they should not define the empirical object.

## Viability Shape

The outer Omega object is closer to a viability kernel than to a static
distinction set.

A future branch remains admissible when there are policies, processes, or
continuation modes that keep valuer-like trajectories inside a viable
compatibility region under declared uncertainty.

A branch is pruned when it violates:

```text
robustness
compatibility
irreversibility constraints
valuer-preservation constraints
correction-channel retention
distributed-agency retention
```

This motivates a working finite object:

```text
Omega_T = MaxAdm({
  trajectory family over horizon T
  satisfying declared viability, robustness, compatibility, and irreversible
  loss constraints
})
```

The exact definition remains future formal work.

## False Positives To Kill

The roadmap should be organized around blocking false objects.

```text
robust process != valuer
high agency != Omega-compatible
many future branches != value-bearing future
self-preservation != value
local distinction recovery != valuerhood
singleton control != compatibility
```

Examples that should remain explicit controls:

```text
crystals
clocks
constant channels
hurricanes
cancer-like lineages
self-replicating malware
paperclip-style optimizers
authoritarian institutions
externally maintained persistence
high-reachability destructive singletons
```

The central discriminator is:

```text
Does this trajectory family preserve and expand compatible valuerhood,
or merely preserve itself?
```

downstream.

## Near-Term Roadmap

1. Keep Alpha as the primitive grammar.

2. Keep distinction transport as audit machinery for recoverability and
   theorem transfer.

3. Freeze broad FFA expansion until trajectory-level targets are formalized.

4. Add finite Lean scaffolds for trajectories, process-bundles, viability,
   compatibility, irreversible loss, and singleton-control counterexamples.

5. Build a small trajectory-level empirical toy model with action channels,
   perturbation, restoration, competing or cooperating process-bundles, and
   irreversible destruction controls.

6. Reuse registry-first provenance discipline for every empirical claim:
   predeclared manifests, digest chains, retained or reconstructible path
   evidence, declared vs existence vs optimized separation, and adversarial
   audits.

## North Star

The project seeks formal support for the intuition that value is not a property
of arbitrary states, but of futures containing valuers.

Alpha supplies the primitive substrate grammar.
Distinction transport supplies formal audit machinery.
Viability theory supplies the trajectory-level shape.
Registry-first empirical probes supply provenance discipline.

Omega lives at the level of compatible valuer-bearing futures, not at the level
of isolated distinctions.
