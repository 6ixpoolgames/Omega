## Rebuild and check

From the repository root, run `python scripts/build_cosmology_v4.py`, then
`python scripts/check_cosmology_v4.py`. The builder's `--check` mode detects a
stale complete manuscript. `--drive-export <path>` writes a reading copy with
repository-relative links expanded to the publication branch.

The numbered chapters are authoritative. Earlier editions remain historical.
See [publication checks](publication_checks.json), the
[quantum platform](../../quantum/README.md) and the evidence chapter for the
limits of the results. Raw simulation output is not part of this edition.
