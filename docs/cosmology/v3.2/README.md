The numbered chapters are the editing source. Rebuild the combined reading
edition from the repository root:

    python scripts/build_cosmology_v3_2.py
    python scripts/build_cosmology_v3_2.py --check
    python scripts/check_cosmology_v3_2.py

The [publication checks](publication_checks.json) reproduce the new elementary
access and repair witnesses, the dependent-input example and tally arithmetic.
They also check assembly and local link targets. These are bounded checks of
the edition, not a validation of the whole theory.

Publication retains the research history on the active
codex/operational-continuation-comparison branch. It is not a migration,
a software-package version bump, or a claim that the cosmology is validated.
