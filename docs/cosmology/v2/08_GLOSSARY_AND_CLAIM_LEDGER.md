# 08 — Glossary and Claim Ledger

## 1. Working vocabulary

| Term | Meaning in v2 |
| --- | --- |
| Alpha | The optional inquiry into configurations and oriented consequence across admissible domains. It is not an established universal physical engine. |
| Omega | The ambition to characterize maximal or otherwise best-supported value-capable continuation. It does not presently denote one proven scalar or attained endpoint. |
| Block / completion | A whole whose internal events and relations are considered together, without an external advancing present. |
| Multiway graph | A representation of situations and admissible continuations. Quantum versions require amplitudes and interference bookkeeping. |
| Perspective | Situated access, orientation, and organization within a world. |
| Adapter | A formal mapping that represents selected distinctions and operations. An arbitrary adapter need not be a physical perspective or subject. |
| Awareness | Minimal phenomenal presence, used as a working term distinct from elaborated consciousness. |
| Consciousness | Organized phenomenal life, potentially involving cognition, integration, memory, or self-modeling. Its relation to awareness remains open. |
| Habitation | Awareness occurring at a qualifying situated perspective. |
| Phenomenal coupling | The unknown correspondence, identity, or other relationship between physical organization and awareness. |
| Soul invariant | A placeholder for identity or inward continuity across changing embodiments. No conserved physical or phenomenal quantity has been established. |
| Gradient | A consequential oriented difference. A literal mathematical gradient requires a specified function and geometry. |
| Persistence filter | The conditions under which processes or lineages continue to be represented. It does not assign moral merit. |
| Deformer | A process whose organization changes available continuation. |
| Agency | Endogenous, policy-sensitive, feedback-mediated control over continuation, with stronger forms sustaining or revising that control. |
| Vorticality | Recurrent organization through turnover and effects that return through feedback. Literal fluid dynamics is an optional realization. |
| Valuer | A still-open class of loci for which distinctions can matter. Proposed criteria are evidence, not a settled demarcation. |
| Standing | The normative status through which a process's continuation supplies reasons others must consider. It is not proportional to causal power. |
| Futures field | Valuer-relevant structured continuation, assessed through an explicit perspective and model. |
| Lushness | Persistent, differentiated, recursively generative value-capable continuation. A target concept, not an established metric. |
| Regulatory variety | Usable responses relative to disturbances and regulated outcomes, following Ashby. It is task-relative and not itself a moral measure. |
| Excision | Elimination of value-capable differentiation or its regeneration in securing a policy or control regime. |
| Terminal solitude | The closure concern associated chiefly with excisive dominance. Lack of external independent controllers alone is insufficient. |
| Recovery | Restoration of a declared fact under specified actions, resources, uncertainty, and horizon. |
| Viable corridor | Conceptually, persistent generativity between dissolution and sterile closure; operationally, preservation of supplied continuation requirements. |
| GE | Gradient Ethics: the proposed normative significance of preserving and developing value-capable continuation. |
| ODT | Omega Decision Theory: conditional licensing, comparison, and externally grounded arbitration. |
| Aseity | Independence of existence from anything else; distinct from self-causation and from necessity. |
| Apophatic veil | The boundary of justified positive description about actuality and its ultimate ground. |

## 2. Minimal notation

| Symbol | Use |
| --- | --- |
| $\mathcal B$ | A supplied continuation structure. |
| $P$ | A perspective or its declared representation. |

| $\mathcal Q=(\mathcal H,\Psi_0,U)$ | The supplied quantum model. |
| $C_\alpha$, $D(\alpha,\beta)$ | A quantum history class operator and decoherence functional. |
| $R_p$ | An ideal physical record projector, not automatically an awareness operator. |
| $\sim_{\mathcal T}$ | Exact equivalence under a declared family of future protocols. |
| $K_*$ | The controlled invariant corridor in a finite model. |
| $L_{P,T}$ | A placeholder candidate lushness assessment, if one is specified. |

## 3. Claim ledger

| Claim | Current status |
| --- | --- |
| Value requires valuers. | Foundational philosophical commitment. |
| Reality can be understood as one internally differentiated completed whole. | Preferred metaphysical architecture. |
| An adequate representation must retain the distinctions relevant to its claimed predictions. | Formal adequacy requirement, exact or approximate under stated conditions. |
| Quantum regrouping preserves a supplied propagator. | Algebraic consequence of genuine resolutions of identity and linearity. |
| The ideal eraser statistics are compatible with the block-and-perspective picture. | Demonstrated within the supplied quantum model; not exclusive evidence for that interpretation. |
| Awareness causes decoherence or sets a universal physical resolution. | Unestablished conjectural direction; not used in the quantum derivation. |
| Every admissible perspective is inhabited. | Preferred conjecture, requiring an explicit admissible domain and correspondence. |
| Persistence can select for continued organization and replication. | Conditional population-dynamic claim. |
| Selection necessarily favors lushness or ethics. | Not established; contrary regimes remain possible. |
| A generative singleton can match the organization of an integrated plurality. | Live equivalence conjecture requiring a specified map and preserved relations. |
| All singletons culminate in terminal solitude. | Not adopted. |
| A justified corridor constrains policies that claim to preserve it. | Conditional formal claim; normative legitimacy of requirements remains separate. |
| Irreversibility derives a complete system of rights and virtues. | Not established; it motivates specific arguments and heuristics. |
| Lushness has a useful scalar or comparative measure. | Open. Neither existence nor impossibility is asserted generally. |
| Corridor preservation improves competitive AI capability. | Testable conditional hypothesis; no blanket performance claim. |
| Alpha supplies global optima in arbitrary search spaces. | Unestablished ambition requiring specified domains, objectives, and assumptions. |
| The whole is aseitic, necessary, or a conscious divine subject. | Separate metaphysical commitments or conjectures, not consequences of completion alone. |

## 4. The next load-bearing questions

The next formal work should connect an operational valuer candidate to consequences that matter without defining virtue into the candidate. It should then test branch-relative lushness comparisons on matched models that include changing capabilities, correlated trajectories, and horizon variation.

In the awareness branch, the central question is whether an independently grounded correspondence selects a physically adequate class of perspectives or equivalences. In the ethics branch, it is which continuation requirements carry standing and how conflicts acquire legitimate resolution.

The broader metaphysical questions remain available, but no new proof obligation should be answered by silently promoting a metaphor into a premise. A result belongs to the framework only to the extent that its formal object still captures the intended question.
