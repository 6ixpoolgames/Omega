## Relationship to the repository

This is the second edition of the conceptual cosmology packet. Its version is separate from the `omega_v2` and `OmegaV2` implementation namespaces and their [foundation report](../../research_notes/omega_v2/alpha_omega_foundation_report_v0.md). It does not modify the checked implementation or the historical result ledgers.

The packet preserves the distinction between physical record models and awareness, leaves the measure of lushness open, and applies terminal solitude chiefly to excisive control. The theology treats aseity as a metaphysical commitment and retains the apophatic limit on claims about an ultimate ground.
