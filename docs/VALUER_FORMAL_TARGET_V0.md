# Valuer Formal Target v0

Status: reorientation note / formal target scaffold

Scope: current best target for the derived value-relevant object

Claim boundary: this note does not detect valuers, validate Omega, or make
ethical claims. It defines the object the formal and empirical stacks should
work toward.

## Core Correction

The project should not treat persistent distinctions as the final object of
concern.

The corrected ladder is:

```text
No valuers -> no value.
No compatible future trajectories -> no durable valuers.
No substrate distinctions -> no recoverable valuers.
```

Distinction persistence is therefore necessary, but not sufficient. It is a
substrate condition for recoverable process structure. The value-relevant object
is a robust valuer-bearing trajectory, not an isolated distinction.

## Target Object

A valuer is not primitive. It is a derived mesoscale object.

For the current research program, a candidate valuer-trajectory should be
treated as a temporally extended process-bundle that satisfies evidence for:

```text
persistence:
  the process remains identifiable enough across time and perturbation

agency:
  the process has action channels with counterfactual effect on future
  trajectories

valuation:
  the process differentiates futures as mattering differently for its continued
  coherent agency

robustness:
  the process is not a one-step artifact, brittle classifier, or transient
  optimization shadow

generativity:
  the process participates in future branching, correction, learning,
  reproduction, cultural continuity, or other continuation modes

compatibility:
  its continuation does not systematically require destroying, capturing, or
  collapsing other valuer-trajectories
```

These are not labels to emit directly from a raw empirical run. They are formal
target conditions. An empirical instrument should emit lower-level evidence
rows that can support, block, or refine these conditions.

## Relation To Alpha

Alpha supplies the primitive grammar:

```text
relation
distinction
asymmetry
```

That grammar is necessary for valuerhood to become formally legible:

```text
relation:
  trajectories, channels, actions, perturbations, interactions

distinction:
  recoverable differences that a process maintains, acts on, or makes relevant

asymmetry:
  non-neutral dynamics that preserve, suppress, channel, or irreversibly alter
  distinctions across time
```

But Alpha does not define value. It defines the lower-level roles needed to ask
which process-bundles are recoverable, robust, action-capable, and compatible.

## What Distinction Persistence Means Now

The older slogan:

```text
Value exists where distinctions persist.
```

should be read only as a substrate-level condition.

The sharper version is:

```text
Value exists only where there are valuers.
Valuers require persistent action-relevant distinctions.
Therefore distinction persistence is a necessary substrate condition for value,
not value itself.
```

This blocks trivial false positives:

```text
rocks
clocks
constant channels
static lock-in
high entropy noise
self-replicating malware
destructive optimizers
externally maintained persistence
```

Persistence must be future-bearing, recoverable, robust, and compatible with
the continuation of other valuer-like processes.

## Evidence Surfaces

Future empirical instruments should prefer evidence surfaces such as:

```text
process_bundle_persistence
action_channel_counterfactual_effect
valuation_proxy_manifest
viability_under_perturbation
restoration_or_correction_channel_retention
branching_continuation_capacity
distributed_agency_retention
compatibility_with_other_process_bundles
irreversible_valuerhood_loss_risk
singleton_control_counterexample
```

The instrument should not emit:

```text
valuer_detected
value_detected
Omega_validated
compatibility_detected
```

Those remain downstream claims that require formal definitions, nulls,
statistical controls, and substrate-bridge arguments.

## Near-Term Formal Work

The next formal layer should define finite scaffolds for:

```text
trajectory families
process-bundle persistence predicates
action-channel counterfactuality
viability predicates
compatibility predicates
maximal admissible trajectory families
irreversible loss examples
pairwise-vs-joint compatibility failures
singleton-control counterexamples
```

The goal is to make false routes unavailable:

```text
mere persistence != valuerhood
mere agency != compatibility
mere branching != value
mere self-preservation != Omega
distinction recovery != value detection
```

## Working Target

The current formal target is:

```text
robust recoverable persistence of future-bearing agency under compatibility
constraints
```

If this target fails under formal or empirical stress, the project should update
the objective downward to a narrower arithmetic of recoverability,
composition, or viable trajectory structure.
